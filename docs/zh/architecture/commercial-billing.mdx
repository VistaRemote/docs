# 订单、订阅与多端功能拦截

## 付费形态

| 形态 | 说明 |
| :--- | :--- |
| **订阅** | 月付 / **年付（约 84–85 折）**；到期需续费 |
| **买断** | 一次付费，对应套餐长期有效 |

商品 SKU 与价格示意见 `shared/src/billing/catalog.ts`。

## 试用与拦截

与 [试用期与付费能力](./commercial-trial) 相同：**SFU**、**AI 降云** 试用结束后须付费。

| 端 | 拦截方式 |
| :--- | :--- |
| Server | 信令拒绝第二观众；降云 Job 不入队 |
| Web Client | `FeatureGate` + `/api/v1/billing/entitlements` |
| Desktop | 降云前 `assertCloudInferAllowed` |
| Mobile | `fetchEntitlements` / `canUseSfu` |

## 支付渠道

中央 Entitlement 已实现微信 / 支付宝 / PayPal / Stripe 等 **adapter**（含 sandbox fixture）；**live 商户启用**（凭证、notify DNS、`enabled=true`）为 **owner-ops**，不随 VistaRemote 交付。银行卡后续。

开发环境可用 `POST /api/v1/billing/orders/:id/simulate-paid`（订单所有者）模拟开通。`ENTITLEMENT_MODE=enforce` 时微信/支付宝走 Entitlement sandbox（`wechat`→`wechat_pay_v3`，`alipay`→`alipay_f2f`），密钥不进 git。管理台订单页仅本地 `local_billing`。**1.27.0**：Client Membership 收银台选 catalog **`providerHint`**（`wechat` / `alipay`），由 BFF 映射到上述 Entitlement adapter，勿在 UI 暴露 adapter id。**1.28.0**：commerce 支付后轮询 **complete** 并同步本地 **User.plan**，Admin 用户列表即时反映套餐，不依赖生产 webhook 延迟。**1.29.0**：lite `POST /api/v1/commerce/webhooks/entitlement`（`X-Entitlement-Signature` = `ENTITLEMENT_WEBHOOK_SECRET`）亦可同步 **User.plan**；非生产微信/支付宝 PSP。**1.30.0**：管理台系统页只读展示 `entitlementMode` / `baseUrlConfigured` / `webhookSecretConfigured`（无密钥明文）。生产核对清单（mock → sandbox → production；env **仅名称**；错误签名 401；commerce 禁 simulate-paid）见 [生产支付就绪](/user/payment-production)；微信/支付宝商户进件为 owner-ops，不随仓交付。
