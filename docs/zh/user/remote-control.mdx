# 远程控制（用户指南）

面向 **使用 VistaRemote 进行远程协助** 的操作人员，非开发人员。

## 角色

| 角色 | 典型场景 |
| :--- | :--- |
| **被控端** | 办公室 PC 安装 Desktop Agent，展示配对码 |
| **主控端** | 管理员用手机/浏览器输入配对码，查看并操作远程桌面 |

## 连接方式（主控端）

任选一种即可直连同一台被控电脑：

| 方式 | 操作 |
| :--- | :--- |
| **数字码** | 在被控端查看 6–8 位码，在主控「配对」页输入 |
| **二维码** | 主控扫描被控屏幕上的码（手机/Web） |
| **链接** | 打开被控提供的 `https://…/join/…` 或企业下发的短链 |

Web 用户端路径：`/pairing`、`/join/{token}`。

## 快速步骤

### 被控端（Desktop）

1. 安装 VistaRemote Agent（Windows / macOS / Linux）。
2. 使用企业账号登录（或注册设备）。
3. 在界面查看 **配对码 / 二维码 / 会话链接**（Consumer 需手动开始共享；企业 Managed 可能由 IT 预装自动上线，见 [Agent 安装](/user/agent-installation)）。
4. 告知主控任选一种方式连接；对方连接后 **确认授权** 再开始共享屏幕（若策略要求）。

### 主控端（Web 或 Mobile）

1. 打开企业提供的 VistaRemote 地址（浏览器或 App）。
2. 在「配对」页输入配对码。
3. 等待状态变为 **已连接** 后即可看到远程画面并操作键鼠。

技术实现细节见 [配对与连接](/guide/pairing)（开发者向）。

## 连接质量

| 情况 | 建议 |
| :--- | :--- |
| 画面卡顿 | 检查双方网络；企业可配置 TURN 中继 |
| 仅局域网可用 | 联系 IT 开放 UDP 或部署 TURN |
| 多人观看同一会话 | 需 **Pro/Enterprise** 套餐（SFU）；试用结束后可能受限 |

## 多显示器（主控 Web）

被控端有两块及以上屏幕时：

| 操作 | 说明 |
| :--- | :--- |
| 工具栏切屏 | 单路模式：切换当前观看/控制的远程显示器 |
| **多窗口** | 最多同时显示 **2** 路画面（同页双格或「弹出窗口」）；每格独立控制，不串屏 |
| 退出多窗口 | 回到单路；仍可用工具栏切屏 |
| 三块及以上屏 | P2P 只并行 2 路；其余屏通过切屏或后续 SFU 覆盖 |

## 被控端 Agent

- 关闭窗口后 Agent **仍在系统托盘运行**；可从托盘恢复窗口、断开会话或退出。
- 托盘可勾选「开机时启动」。
- **Linux**：X11 / XWayland 可直接注入；纯 Wayland 需在系统弹出的屏幕共享与远程桌面门户中授权，步骤见 [Linux 已登录远控](/guide/linux-remote-control)。

## 剪贴板、文件、终端、聊天、进程、服务与电源（Web / Viewer）

会话已连接且被控授权后，右侧面板可：

- 双向同步**纯文本**剪贴板（被控复制后主控会更新）
- 浏览被控用户主目录、上传/下载、新建文件夹、删除（jail 内）
- **xterm** 终端（Windows ConPTY / POSIX 真 PTY；如 `echo` / `dir` / `tput cols`）
- 与被控桌面**会话聊天**
- 查看进程并结束任务（不能结束系统 pid 或 Agent 自身）
- **只读**查看系统服务列表（不能远程启动或停止服务）
- **重启 / 关机**（须二次确认字面量；数秒后才执行）

无对应权限的账号看不到终端、服务或电源页。本产品不做 Intel AMT、远程打印、注册表、WOL 魔术包。

- 被控在 Agent 窗口**允许**后才可键鼠/运维；拒绝则仅观看。被控桌面会显示置顶**连接条**，可一键断开。断开后立即停止注入与运维通道。

## 安全提示

- 勿将配对码发给无关人员；配对码会过期，且 **一次性消费**（`PAIRING_CONSUMED`），班级不能共用一个码。
- 结束会话后关闭 Agent 或断开共享。
- 企业版可启用审计与行为策略（由管理员配置）。
