## 1. 我们有什么能力

**VistaRemote** 不只是一对一远程桌面。面向企业与边缘现场，产品具备完整的 **设备舰队（Device Fleet）** 能力：

| 能力 | 一句话 | 典型场景 |
| :--- | :--- | :--- |
| **一对一远程桌面** | 高质量看屏 + 键鼠 + 文件 / 终端 | 技术支持、运维排障 |
| **群控键鼠** | 一台主控，同步操作多台已授权设备 | 机房巡检、批量配置、教学演示 |
| **批量命令** | 对多台设备下发通知、锁屏、重启、打开链接等 | 下班锁屏、统一提醒、应急处置 |
| **多屏监控墙** | 多路缩略图低成本观察，异常点选切入高质量控制 | 值班室、运维大屏、边缘网点巡检 |
| **虚拟显示器** | 为远控创建专用虚拟屏，减少打扰本机物理桌面 | 客服远控、无人值守工位、合规桌面 |
| **带外管理（OOB）** | Intel AMT 等带外电源 / BIOS / KVM（企业私有化） | 关机态机器、未进系统时的运维 |
| **审计与 RBAC** | 操作可追溯，组织权限可管 | 合规、IT 分权 |

与 **VistaCast** 组合时：**Cast 看业务视频，Remote 管边缘计算设备** — 可形成「摄像头 + Edge AI Box + VistaRemote 管理」的 B2B 方案。

## 2. 谁可以用、怎么开通

| 能力族 | 套餐 | 开通方式 |
| :--- | :--- | :--- |
| 核心 1:1 远控 | Free / Pro / Enterprise | 产品默认路径 |
| 舰队：群控、批量命令、监控墙、虚拟屏 | **Enterprise** | 购买企业服务后开通对应权益 |
| 带外 OOB / AMT | **Enterprise + 私有化** | 合同约定现场与交付范围 |
| 监控墙更大槽位（如数十上百路观察） | **Enterprise 合同加购** | 按采购需求验收槽位与 SLA |

**销售与交付口径（产品承诺）**

- 上表能力均为 **产品能力范围**：对外介绍、标书与方案书可写「具备」。
- 企业客户购买或签订合同后，团队按现场需求 **开通、调优或加购**；部分能力可在采购确认后按合同节奏交付与验收。
- 终端管理本身可独立计价（按设备 / 席位），不只是远控的附属打勾项。

具体报价与开通流程请联系销售或贵司实施方；套餐总览见 [套餐与付费](/user/plans-and-billing)。

## 3. 多屏监控墙：怎么用才省带宽

监控墙的产品设计是：

```text
缩略图墙（低成本观察）
        ↓ 发现异常
点选设备（须企业权益）
        ↓
高质量 Remote Session（控制）
```

| 模式 | 用途 |
| :--- | :--- |
| **缩略图观察** | 约低分辨率、低帧率预览，适合同时看多台在线设备 |
| **高质量控制** | 点选后进入 720p / 1080p 级远控会话 |

这样把「100 台设备在线」和「100 路实时高清同屏」分开：前者是舰队管理，后者按合同加购与验收，**不作为默认标配承诺**。企业若需要更大墙面（参考市场常见宣传量级如数十～上百路观察），可在现有架构上按合同开通与验证。

操作入口：管理台 **监控墙**；点选槽位可进入控制会话。详见 [管理控制台](/user/admin-console)。

## 4. 群控与批量命令

### 批量命令

在 **我的设备**（用户端）或管理台 **设备** 中多选设备，可下发：

- 桌面通知  
- 锁屏  
- 重启 / 关机（须确认字面量）  
- 打开 http(s) 链接  

每台设备独立返回成功 / 失败，结果可审计。

### 群控键鼠

勾选多台在线设备进入 **群控**：主控在主画面上的键鼠操作，同步到组内已授权（同意闸）的设备。被控端可随时断开；未授权设备不会被隐式控制。

---

## 5. 虚拟显示器

产品支持为远控场景使用 **虚拟显示器**：远控画面落在专用虚拟屏上，减少对员工本机物理桌面的打扰，并可与隐私屏、多显示器策略协同。

- **企业开通** `虚拟显示器` 权益后，在 Agent 侧启用与管理。  
- Windows 为企业优先交付平台；其他平台按合同约定。  
- 若现场需要与特定驱动 / 镜像策略集成，销售与交付可在企业采购后按现场方案落地。

---

## 6. 带外管理（AMT 等）

对关机、未进入操作系统的机器，Enterprise 私有化可提供 **带外管理**（如 Intel AMT：电源、BIOS、带外 KVM）。公有默认路径以 Agent 在线运维为主；带外能力按 **企业合同 + 私有化部署** 开通，不占用个人免费版资源。
