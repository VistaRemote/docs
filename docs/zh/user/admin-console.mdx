# 管理控制台（用户）

面向 **企业 IT / 管理员**，管理用户、设备、会话与合规数据。

**1.11.0** 起，下列列表来自服务端真实数据，不是演示数据。**1.13.0** 起，订单 / 组织 / 录制支持 **CSV 导出**（用户、设备、安全事件、任务此前已支持）；设备可按 **在线 / 离线** 筛选；审计可按结果 **ok | denied | error** 筛选；安全事件可按 **设备 ID** 筛选；概览展示 **组织数** 与 **待支付订单**。**1.14.0** 起，会话 / 权限矩阵也可导出 **CSV**；用户可按 **组织 ID** 筛选；效率报告可按 **用户 ID / 会话 ID** 筛选；任务可按 **ID** 筛选；审计可按 **资源类型** 筛选。角色说明见 [认证与授权](/architecture/authorization)。

## 访问

- 地址通常为 `https://<your-domain>/admin`（由部署方提供）
- 使用 **平台管理员** 或 **组织管理员** 账号登录

## 主要模块

| 模块 | 作用 |
| :--- | :--- |
| **概览** | 实时计数卡片，含 **组织数**、**待支付订单**，以及用户、会话、录制、设备 / 在线设备等 |
| **用户** | 查看/筛选（含 **组织 ID**）/创建/禁用账号，分配组织与套餐；导出 **CSV** |
| **设备** | 被控机 **在线** 状态（心跳约 120 秒内视为在线）、**在线 / 离线** 与 **标签** 筛选、标签编辑、吊销设备；导出 **CSV** |
| **会话** | 活跃远程房间（p2p / SFU）；管理员可 **强制断开**；列表可筛选；导出 **CSV** |
| **录制** | 按用户、状态、会话、触发方式 **筛选**；导出 **CSV**；内嵌播放器支持 **seek** 与 **倍速回放** |
| **审计** | 按主体、动作预设、时间、资源 / **资源类型**、**结果（ok / denied / error）** 筛选；导出 **CSV** |
| **安全事件** | 外发风险、批量删除、行为推理等；按类型、**设备 ID** 筛选，高危有横幅；可跳转到关联录制时间点；导出 **CSV** |
| **组织** | 组织、席位/成员与策略（关键词、域名等）；导出 **CSV** |
| **订单** | 按用户、SKU、状态筛选套餐订单；导出 **CSV**（开通仍靠管理员改套餐，无真实支付） |
| **系统** | ICE/TURN 只读状态（密钥已掩码）；浏览器 **ICE 探测**；配对码策略 |
| **任务** | 后台任务（如录制摘要）列表；按 **ID / 名称 / 状态** 筛选与失败重试；导出 **CSV** |
| **效率报告** | 按本周/本月汇总录制分钟数；可按 **用户 ID / 会话 ID** 筛选后再汇总（基于录制元数据，不是 LLM 效率模型）；导出 **CSV** |
| **权限** | 平台/组织权限矩阵 **只读**；可导出对照 **CSV**（不可编辑角色绑定） |

## 常见操作

### 为用户开通 Pro

1. 确认已按企业流程完成付款或合同订单（本版本 **没有** 微信/支付宝真实支付；开通靠管理员改套餐）。
2. 在「用户」列表中将该账号套餐设为 `pro`，并填写有效到期日。
3. 用户重新登录或刷新客户端后生效。

### 禁用用户

1. 用户列表 → 选择用户 → 禁用。
2. 该用户无法新建远程会话。进行中的会话请到「会话」执行 **强制断开**。

## 本版本尚未提供

请勿按下列能力做验收或对外承诺：

- 端侧 **MediaRecorder** 出片与 **MinIO** 产品级播放器（当前为元数据列表 + 简易倍速回放）
- 可编辑 **权限矩阵**（权限页为只读对照）
- 多路 **监控墙**
- 真实 **微信 / 支付宝** 支付

未完成项见 [实现状态](/engineering/implementation-status)。

## 安全建议

- 管理台仅内网或 VPN 暴露，或启用 MFA（规划中，P1）。
- 敏感操作（禁用用户、改套餐、强制断开、吊销设备）请用「审计」筛选，并按需导出 CSV。
