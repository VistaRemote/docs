# 管理控制台

面向 **企业 IT / 管理员**。在同一控制台管理用户、设备、会话、录制、订单与合规数据。

## 访问

- 地址由部署方提供，通常为 `https://<your-domain>/admin`
- 使用 **平台管理员** 或 **组织管理员** 账号登录

## 主要模块

| 模块 | 作用 |
| :--- | :--- |
| **概览** | 组织、用户、在线设备、会话、待支付订单、失败录制与失败任务等计数，并可跳到对应列表 |
| **用户** | 查看、筛选、创建、禁用账号，分配组织与套餐；详情可跳到该用户的会话、录制、配对、订单、设备与审计；支持导出 CSV |
| **设备** | 在线 / 离线（心跳约 120 秒内视为在线）、所有者、组织与标签筛选；编辑标签、吊销设备；有会话时可进入监控墙；支持导出 CSV |
| **配对** | 查看近期配对码，按设备、用户、配对码、是否已使用筛选，并跳到设备、用户或会话 |
| **会话** | 查看 P2P / SFU 房间；强制断开或旁观；按用户筛选；支持导出 CSV |
| **录制** | 按用户、设备、状态、会话与触发方式筛选；浏览器内回放（可拖动进度、倍速）；支持导出 CSV |
| **审计** | 按操作者、动作、时间、资源与结果（成功 / 拒绝 / 失败）筛选；监控墙布局变更可跳回监控墙；支持导出 CSV |
| **安全事件** | 外发、批量删除等风险事件；可按类型、设备、用户、组织筛选，并设置静音类型；可跳到关联会话、设备或录制 |
| **组织** | 组织、席位与成员角色；IT 临时协助授权（创建、查看、撤销，撤销时可断开相关会话）；支持导出成员与授权 CSV |
| **订单** | 按用户、商品、支付渠道与状态查看套餐订单，并可跳到该用户的会员信息 |
| **会员** | 用户在 Web 用户端完成微信 / 支付宝等支付；支付完成后套餐写入用户资料，管理台用户列表立即可见 |
| **系统** | 查看权益与支付是否已配置（不展示密钥），复制 ICE / TURN 与配对策略，并打开配对列表 |
| **任务** | 查看录制摘要等后台任务，按状态筛选，失败可重试；摘要任务可跳到对应录制 |
| **效率报告** | 按周 / 月汇总录制时长，并可按用户、会话、设备、录制筛选后打开录制列表 |
| **权限** | 查看平台与组织权限对照，分配平台操作员与组织成员角色；支持导出 CSV |
| **监控墙** | 多路缩略图观察，点选后进入高质量远控；布局可保存。属 Enterprise，见 [设备舰队与企业能力](/user/fleet-and-enterprise) |

列表筛选会写进地址栏，便于收藏和从概览深链打开。

## 常见操作

### 为用户开通套餐

1. 管理台 **用户** 中直接调整套餐。
2. 或让用户打开 Web 用户端会员页，选择微信或支付宝完成支付。支付确认后，用户列表显示对应套餐。
3. 用户刷新客户端或重新登录后，远程、录制与 AI 等权益生效。

### 禁用用户

1. 在用户列表中禁用该账号。
2. 该用户不能再发起新的远程会话。进行中的会话在 **会话** 中 **强制断开**。

### 监控墙

1. 打开监控墙，把活跃会话放到槽位上。
2. **保存布局**（需要写入权限）后，下次打开会恢复。地址栏也可预填槽位。
3. 缩略图用于值班观察；需要操作时点进该路，进入控制会话。

更大槽位按企业合同开通，说明见 [设备舰队与企业能力](/user/fleet-and-enterprise)。

### 查配对码

打开 **配对**，按设备、用户或配对码筛选。码长与有效期在 **系统** 的配对策略中配置。配对码仍由被控 Agent 生成。

### 从一个人查到相关记录

打开用户详情，可进入该用户的会话、录制、配对、订单、设备与审计。设备上若有进行中的会话，可直接进入监控墙。

## 企业能力

群控、更大的监控墙、可配置的告警策略，以及生产环境的微信 / 支付宝商户，按 Enterprise 与合同开通。说明见 [设备舰队与企业能力](/user/fleet-and-enterprise)。

## 安全

管理台随产品部署在你的服务器上，用统一账号登录，不依赖把控制台藏进内网。

- **注册**：第一次注册要验证邮箱。之后用邮箱和密码登录，不必每次收验证码。
- **可选的动态口令**：用户可以在账号里绑定验证器。微软 Authenticator 可以用，它扫的是标准动态口令，应用本身免费，不需要微软的付费套餐。也可以用其他验证器。不绑定也能登录。
- **组织要求时**：某个组织可以要求成员必须完成这一步。
- 禁用用户、改套餐、强制断开、吊销设备等操作，到 **审计** 中筛选并按需导出。

角色说明见 [认证与授权](/architecture/authorization)。运维问答见 [常见问题](/user/faq)。开发者入门见 [管理端快速开始](/guide/admin-getting-started)。

## 支付

| 方式 | 说明 |
| :--- | :--- |
| 管理员改套餐 | 在 **用户** 中直接写入套餐 |
| 用户支付 | Web 用户端会员页选择微信或支付宝，支付完成后套餐生效 |
| 权益配置 | **系统** 页只读展示权益服务是否已接好，不展示密钥 |

生产环境核对见 [生产支付就绪](/user/payment-production)。
