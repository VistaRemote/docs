# 管理控制台（用户）

面向 **企业 IT / 管理员**，管理用户、设备、会话与合规数据。

**1.11.0** 起，下列列表来自服务端真实数据，不是演示数据。角色说明见 [认证与授权](/architecture/authorization)。

## 访问

- 地址通常为 `https://<your-domain>/admin`（由部署方提供）
- 使用 **平台管理员** 或 **组织管理员** 账号登录

## 主要模块

| 模块 | 作用 |
| :--- | :--- |
| **用户** | 查看/筛选/创建/禁用账号，分配组织与套餐 |
| **设备** | 被控机 **在线** 状态（心跳约 120 秒内视为在线）、**标签** 编辑与筛选、吊销设备 |
| **会话** | 活跃远程房间（p2p / SFU）；管理员可 **强制断开** |
| **录制** | 按用户、状态、会话、触发方式 **筛选**；内嵌播放器支持 **seek** 与 **倍速回放** |
| **审计** | 按主体、动作预设、时间、资源 **筛选**；导出 **CSV** |
| **安全事件** | 外发风险、批量删除、行为推理等；按类型筛选，高危有横幅；可跳转到关联录制时间点 |
| **组织** | 组织、席位/成员与策略（关键词、域名等） |
| **系统** | ICE/TURN 只读状态（密钥已掩码）；浏览器 **ICE 探测**；配对码策略 |
| **任务** | 后台任务（如录制摘要）列表、筛选与失败重试 |
| **效率报告** | 按本周/本月汇总录制分钟数（基于录制元数据，不是 LLM 效率模型） |

## 常见操作

### 为用户开通 Pro

1. 确认已按企业流程完成付款或合同订单（本版本 **没有** 微信/支付宝真实支付；开通靠管理员改套餐）。
2. 在「用户」列表中将该账号套餐设为 `pro`，并填写有效到期日。
3. 用户重新登录或刷新客户端后生效。

### 禁用用户

1. 用户列表 → 选择用户 → 禁用。
2. 该用户无法新建远程会话。进行中的会话请到「会话」执行 **强制断开**。

## 本版本尚未提供

请勿按下列能力做验收或对外承诺：

- 端侧 **MediaRecorder** 出片与 **MinIO** 产品级播放器（当前为元数据列表 + 简易倍速回放）
- 可编辑 **权限矩阵**（权限页为只读对照）
- 多路 **监控墙**
- 真实 **微信 / 支付宝** 支付

未完成项见 [实现状态](/engineering/implementation-status)。

## 安全建议

- 管理台仅内网或 VPN 暴露，或启用 MFA（规划中，P1）。
- 敏感操作（禁用用户、改套餐、强制断开、吊销设备）请用「审计」筛选，并按需导出 CSV。
