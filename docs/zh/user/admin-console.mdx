# 管理控制台（用户）

面向 **企业 IT / 管理员**，管理用户、设备、会话与合规数据。

**1.11.0** 起，下列列表来自服务端真实数据，不是演示数据。**1.13.0** 起，订单 / 组织 / 录制支持 **CSV 导出**（用户、设备、安全事件、任务此前已支持）；设备可按 **在线 / 离线** 筛选；审计可按结果 **ok | denied | error** 筛选；安全事件可按 **设备 ID** 筛选；概览展示 **组织数** 与 **待支付订单**。**1.14.0** 起，会话 / 权限矩阵也可导出 **CSV**；用户可按 **组织 ID** 筛选；效率报告可按 **用户 ID / 会话 ID** 筛选；任务可按 **ID** 筛选；审计可按 **资源类型** 筛选。**1.15.0** 起，用户 / 安全事件可按 **用户 ID** 筛选；设备可按 **owner / org** 筛选且概览「在线设备」可深链；订单可按 **支付渠道** 筛选；组织详情可导出 **成员 CSV**；系统页可 **复制 ICE 探测结果**；录制可按 **录制 ID / 设备 ID** 筛选。**1.18.0** 起，设备 / 录制 / 组织 / 会话 / 任务 / 订单列表筛选走 **服务端 query**；概览「失败录制」可深链；效率报告可按 **设备 ID** 筛选。**1.19.0** 起，多数列表支持 **URL 查询种子**（含用户套餐过期、组织席位、审计结果、会话模式等）；概览可深链到过期用户 / 席位超额 / 拒绝审计 / SFU 会话；系统页可 **复制 TURN URL**；效率报告可按 **录制 ID** 筛选。**1.20.0** 起，录制 / 订单 / 会话 / 组织 / 任务 / 安全 / 报告 URL 种子补齐；权限矩阵可按权限字搜索；概览增加离线设备 / 席位可用 / 过期录制 / 已支付订单深链。**1.21.0** 起，审计可按 **fromTs / toTs** URL 种子；系统页可复制 **ICE 摘要 / 配对策略 JSON**；权限搜索支持 `q` / `perm` URL；组织成员可按角色筛选；概览有 **效率报告** 入口。**1.25.0**（Scope C）起：Agent **MediaRecorder** 分片上传可回放；**权限**页可改平台操作员角色、组织可改成员 `orgRole`（矩阵仍只读）；订单区分 local_billing / commerce；安全事件可跳会话/设备；会话可 **旁观**；运行时有 **2×2 监控墙**壳（完整 SFU 多路仍后置）。角色说明见 [认证与授权](/architecture/authorization)。

## 访问

- 地址通常为 `https://<your-domain>/admin`（由部署方提供）
- 使用 **平台管理员** 或 **组织管理员** 账号登录

## 主要模块

| 模块 | 作用 |
| :--- | :--- |
| **概览** | 实时计数卡片，含 **组织数**、**待支付订单**，以及用户、会话、录制、设备 / 在线设备等 |
| **用户** | 查看/筛选（含 **用户 ID**、**组织 ID**）/创建/禁用账号，分配组织与套餐；导出 **CSV** |
| **设备** | 被控机 **在线** 状态（心跳约 120 秒内视为在线）、**在线 / 离线**、**owner / org**、**标签** 筛选、标签编辑、吊销设备；导出 **CSV**（概览「在线设备」可深链到在线筛） |
| **会话** | 活跃远程房间（p2p / SFU）；管理员可 **强制断开** / **旁观**（单路）；列表可筛选；导出 **CSV** |
| **录制** | 按用户、**录制 ID**、**设备 ID**、状态、会话、触发方式 **筛选**；导出 **CSV**；内嵌播放器支持 **seek** 与 **倍速回放** |
| **审计** | 按主体、动作预设、时间、资源 / **资源类型**、**结果（ok / denied / error）** 筛选；导出 **CSV** |
| **安全事件** | 外发风险、批量删除、行为推理等；按类型、**设备 ID**、**用户 ID**、**组织 ID** 筛选，高危有横幅；可跳转到关联录制时间点 / **会话 / 设备**；导出 **CSV** |
| **组织** | 组织、席位/成员与策略（关键词、域名等）；可改成员 **orgRole**；列表导出 **CSV**；详情可导出 **成员 CSV** |
| **订单** | 按用户、SKU、**支付渠道**、**来源（local_billing）**、状态筛选套餐订单；导出 **CSV**。本页是 **本地计费** 订单，不是 Entitlement 商务单。开发环境可对本地 pending 单点「模拟支付」；**禁止**用 Admin JWT 去 `/billing/.../simulate-paid` 或代付他人 commerce 订单。 |
| **系统** | ICE/TURN 只读状态（密钥已掩码）；浏览器 **ICE 探测** 与 **复制探测结果**；配对码策略 |
| **任务** | 后台任务（如录制摘要）列表；按 **ID / 名称 / 状态** 筛选与失败重试；导出 **CSV** |
| **效率报告** | 按本周/本月汇总录制分钟数；可按 **用户 ID / 会话 ID** 筛选后再汇总（基于录制元数据，不是 LLM 效率模型）；导出 **CSV** |
| **权限** | 平台/组织权限矩阵 **只读**；可导出对照 **CSV**；可分配 **平台操作员** 角色（非勾选改 Permission） |
| **监控墙** | 2×2 会话占位壳，槽位可跳转到旁观；多路 SFU 墙后置 |

## 常见操作

### 为用户开通 Pro

1. 生产开通：走 Entitlement **sandbox** 微信/支付宝（见下文），或确认合同后在「用户」改套餐。
2. 开发快捷：用户用 **Controller JWT** 调 `POST /api/v1/billing/orders/:id/simulate-paid`（仅自己的 **本地** 订单）。管理台「模拟支付」只打本地 `source=local_billing` 单，**不会**代付 commerce。
3. 用户重新登录或刷新客户端后生效。

### 禁用用户

1. 用户列表 → 选择用户 → 禁用。
2. 该用户无法新建远程会话。进行中的会话请到「会话」执行 **强制断开**。

## 本版本尚未提供

请勿按下列能力做验收或对外承诺：

- 端侧 **MediaRecorder** 出片与 **MinIO** 产品级播放器（当前为元数据列表 + 简易倍速回放）
- 可编辑 **权限矩阵**（权限页为只读对照）
- 完整多路 **SFU 监控墙**（当前仅旁观 + 2×2 壳）
- 生产 **微信 / 支付宝** 密钥（密钥不得进 git；sandbox 由 Entitlement 配置）

未完成项见 [实现状态](/engineering/implementation-status)。

## 安全建议

- 管理台仅内网或 VPN 暴露，或启用 MFA（规划中，P1）。
- 敏感操作（禁用用户、改套餐、强制断开、吊销设备）请用「审计」筛选，并按需导出 CSV。

## 支付与 Entitlement（mock → sandbox）

| 模式 | 行为 |
| :--- | :--- |
| `ENTITLEMENT_MODE=off`（默认） | 本地套餐/订单；不访问中央 Entitlement |
| `ENTITLEMENT_MODE=enforce` | 商务权益与 checkout 以 Entitlement 为准 |
| Mock / 开发 | 用户 `POST /api/v1/billing/orders/:id/simulate-paid`（自己的本地单） |
| Sandbox 微信/支付宝 | `POST /api/v1/commerce/orders/:id/pay`，`wechat`→`wechat_pay_v3`、`alipay`→`alipay_f2f`；密钥只在 Entitlement 环境变量 |
