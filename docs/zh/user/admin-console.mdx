# 管理控制台（用户）

面向 **企业 IT / 管理员**，管理用户、订单与权限。

## 访问

- 地址通常为 `https://<your-domain>/admin`（由部署方提供）
- 使用 **平台管理员** 或 **组织管理员** 账号登录

角色说明见 [认证与授权](/architecture/authorization)。

## 主要模块

| 模块 | 作用 |
| :--- | :--- |
| **用户** | 查看/禁用账号、分配组织角色 |
| **订单** | 查看购买记录、订单状态 |
| **权限** | 套餐与功能开关（SFU、云推理等） |

当前版本部分列表为 **演示数据**；生产需接 PostgreSQL 持久化与真实 JWT（见 [实现状态](/engineering/implementation-status)）。

## 常见操作

### 为用户开通 Pro

1. 确认订单已支付（或手动录入合同订单，视企业流程）。
2. 在「权限」或用户详情中确认套餐为 `pro` 且未过期。
3. 用户重新登录或刷新客户端后生效。

### 禁用用户

1. 用户列表 → 选择用户 → 禁用。
2. 该用户无法新建远程会话；进行中的会话应按策略断开（以实现为准）。

## 安全建议

- 管理台仅内网或 VPN 暴露，或启用 MFA（P1）。
- 审计敏感操作（删除用户、改套餐）。
