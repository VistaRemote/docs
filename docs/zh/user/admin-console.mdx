## 访问

- 地址通常为 `https://<your-domain>/admin`（由部署方提供）
- 使用 **平台管理员** 或 **组织管理员** 账号登录

## 主要模块

| 模块 | 作用 |
| :--- | :--- |
| **概览** | 实时计数卡片，含 **组织数**、**待支付订单**，以及用户、会话、录制、设备 / 在线设备等；可深链到 **/security**、**/system**（权益配置标志）、**/monitor-wall**；**配对** NavCard → `/pairings`（**1.41.0**） |
| **用户** | 查看/筛选（含 **用户 ID**、**组织 ID**）/创建/禁用账号，分配组织与套餐；详情抽屉 **关联深链**（会话 / 录制 / 配对 / 订单 / 设备 / 审计，**1.38.0**；**1.42.0** 补 **配对**）；导出 **CSV** |
| **设备** | 被控机 **在线** 状态（心跳约 120 秒内视为在线）、**在线 / 离线**、**owner / org**、**标签** 筛选、标签编辑、吊销设备；**操作** 列 **配对** → `/pairings?deviceId=`（**1.41.0**）；有活跃会话时 **操作** 可跳 **监控墙**（`s0` 种子，**1.38.0**）；导出 **CSV**（概览「在线设备」可深链到在线筛） |
| **配对** | PostgreSQL 近期配对码 **只读** 列表（**FR-WAD-109**，**1.39.0**）；按 **设备 ID**、**owner 用户 ID**、**配对码**、**已消费**（`yes` = 有 `consumedAt`，`no` = 未使用 — URL 同步，**1.41.0**）筛选；行 **设备** / **用户** / **会话** 链到 `/devices?deviceId=`、`/users?userId=`、`/sessions?sessionId=`（**1.40.0** 会话深链）；配对 **策略**（长度 / TTL）在 **系统** 页，策略区可 **打开配对** → `/pairings` |
| **会话** | 活跃远程房间（p2p / SFU）；管理员可 **强制断开** / **旁观**（单路；**1.36.0** 旁观票据 = shared **AdminObserveTicket**，SFU 桩字段为 null）；可按 **用户 ID** 筛选（**`?userId=`** URL 同步，**1.38.0**）；导出 **CSV** |
| **录制** | 按用户、**录制 ID**、**设备 ID**、状态、会话、触发方式 **筛选**；导出 **CSV**；`failed` 且 **EntityTooSmall / part size** 时状态列 / 失败原因带 **≥5 MiB 合并** 提示；内嵌播放器经 **playback-url** 短时签名拉流（`expiresAt`、过期可刷新；memory `/media`）；支持 **seek** 与 **倍速回放** |
| **审计** | 按主体、动作预设（含 **旁观 / SupportGrant / 操作员与成员角色**、**`pairing.create` / `pairing.join`**（**1.43.0**）与 **监控墙 layout**）、时间、资源 / **资源类型**、**结果（ok / denied / error）** 筛选；**`admin.monitor_wall.layout`** 行可跳 **监控墙**（meta **`roomIds`** / `roomId` → `?s0=`，仅槽位种子，**1.38.0**）；导出 **CSV** |
| **安全事件** | 外发风险、批量删除、行为推理等；按类型、**设备 ID**、**用户 ID**、**组织 ID** 筛选；可编辑 **告警规则 lite**（横幅最低严重度 + 静音类型；非关联引擎）；列表 **默认应用已保存的静音规则**（Switch「**应用静音规则**」；`applyMute=false` 或 URL `?applyMute=false` 显示全部类型）；高危有横幅；可跳转到关联录制时间点 / **会话 / 设备**；导出 **CSV** |
| **组织** | 组织、席位/成员与策略（关键词、域名等）；可改成员 **orgRole**；抽屉内 **SupportGrant**（IT 协助授权）创建 / 列表 / 撤销 / **导出 CSV**（可选「撤销并断开相关会话」，`?kickSessions=true`）；列表导出 **CSV**；详情可导出 **成员 CSV** |
| **订单** | 按用户、SKU、**支付渠道**、**来源（local_billing）**、状态筛选套餐订单；导出 **CSV**。本页是 **本地计费** 订单，不是 Entitlement 商务单。开发环境可对本地 pending 单点「模拟支付」；**禁止**用 Admin JWT 去 `/billing/.../simulate-paid` 或代付他人 commerce 订单。行 **会员** → `/membership?userId=…`（有 **userId** 时，**1.43.0**）；**会员** 页 **打开订单列表** 深链到此页 **`?userId=`**（**1.42.0**） |
| **会员** | Commerce 收银台（试用倒计时、条款接受、SKU 下单与 sandbox 支付）；URL **`?userId=`** 可种子主体用户；有 userId 时标题旁 **打开订单列表** → `/orders?userId=…`（**1.42.0**；亦可在下单 / complete 后从订单响应带出 userId） |
| **系统** | ICE/TURN 只读状态（密钥已掩码）；权益/支付配置标志只读（`entitlementMode`、`entitlementBaseUrlConfigured`、`webhookSecretConfigured`；无密钥）；**复制权益状态 JSON**（仅上述标志）；浏览器 **ICE 探测** 与 **复制探测结果**；配对码策略（**1.40.0** 策略区 **打开配对** → `/pairings`） |
| **任务** | 后台任务（如录制摘要）列表；按 **ID / 名称 / 状态 / 失败原因** 筛选（**URL 同步**；概览「失败任务」→ `?state=failed`）；**`recording.summarize`** 行可跳 **录制**；失败重试；导出 **CSV** |
| **效率报告** | 按本周/本月汇总录制分钟数；可按 **用户 ID / 会话 ID / 设备 ID / 录制 ID** 子串筛选后再汇总（基于录制元数据，不是 LLM 效率模型）；**打开录制列表** 深链携带当前筛；导出 **CSV** |
| **权限** | 平台/组织权限矩阵 **只读**；可导出对照 **CSV**；可分配 **平台操作员** 角色（非勾选改 Permission） |

## 常见操作

### 为用户开通 Pro

1. 生产开通：走 Entitlement **sandbox** 微信/支付宝（见下文），或确认合同后在「用户」改套餐。
2. 开发快捷：用户用 **Controller JWT** 调 `POST /api/v1/billing/orders/:id/simulate-paid`（仅自己的 **本地** 订单）。管理台「模拟支付」只打本地 `source=local_billing` 单，**不会**代付 commerce。
3. 用户重新登录或刷新客户端后生效。

### 禁用用户

1. 用户列表 → 选择用户 → 禁用。
2. 该用户无法新建远程会话。进行中的会话请到「会话」执行 **强制断开**。

### 监控墙布局

**FR-WAD-108 layout 切片（1.35.0）** — 持久化槽位与会话绑定；**不含**跨会话 SFU 多路 live 订阅（该部分 **FR-WAD-108** 仍开，勿按已交付验收）。

1. 打开 **/monitor-wall**。URL 查询 **`s0`–`s3`**（兼容 `slot0`–`slot3`）若带有会话 ID，**优先**填充对应槽位，**不会**被已保存布局覆盖。
2. **无** URL 种子时，页面 **GET** `/admin/monitor-wall/layout` 恢复上次保存的槽位绑定。
3. 调整槽位后须点 **保存布局**，才会 **PUT** 同一接口持久化（须 **admin.write**；只读管理员按钮禁用）。保存布局 **不会**自动发起墙内旁观或 SFU 连接。
4. 各槽 **墙内旁观** 仍是 **FR-WAD-72 MVP** 单路内嵌旁观；完整跨会话 **SFU 多路** 监控墙为 **FR-WAD-108**（Spec 已定，**未交付**；依赖 SFU multi-producer + MD-4）。
5. **1.36.0** — `POST /admin/rooms/:roomId/observe` 返回 shared **AdminObserveTicket**（`signalingTicket`、`role: observe`、`expiresAt` 等）。SFU 字段（`routerId`、`transport`、`consumer`）当前为 **null 桩** — 非 mediasoup-client 握手 DTO；勿按 SFU 多路已交付验收。
6. **1.37.0** / **1.38.0** — 审计动作预设选 **监控墙 layout**（`admin.monitor_wall.layout`）。**1.38.0** 起 **保存布局** 写审计时 meta 含 **`roomIds`**（已绑定槽位的会话 ID 列表）及首个 **`roomId`**。匹配行 **关联** 列 **监控墙** → `/monitor-wall`，或 `/monitor-wall?s0=<roomId>`（meta / resource / target 的 `roomId` / `room_id`）。仅填充槽位 0 种子 — **不会**自动发起 SFU 多路或墙内旁观。

### 任务、报告与录制（1.37.0）

1. **任务** — 列表筛（`id`、`name`、`state`、`failedReason`）搜索后与 **URL 同步**（可分享链接；概览「失败任务」打开 `/jobs?state=failed`）。
2. **录制摘要任务** — 类型 `recording.summarize` 且 id 为 `summarize-{recordingId}` 的行，**操作** 列有 **录制**，链到 `/recordings?recordingId=…`（其他任务类型无此跳转）。
3. **效率报告** — **打开录制列表** 打开 `/recordings`，携带当前子串筛（`userId`、`sessionId`、`deviceId`、`recordingId`）；无筛时打开全列表。

### 配对列表（1.39.0 / 1.40.0 / 1.41.0）

**FR-WAD-109** — 近期配对码只读运维视图；**不是**发码器，也与监控墙无关。

1. 打开 **/pairings**（侧栏 **运营管理** → **配对**，在 **设备** 与 **订单** 之间）；从 **概览** → **配对** NavCard（**1.41.0**）；从 **设备** → **操作** → **配对**（预填 `?deviceId=`，**1.41.0**）；或从 **系统** 页 **配对策略** 区点 **打开配对**（**1.40.0**）。
2. 页面调用 **GET** `/api/v1/admin/pairings`（须 **admin.read**）。默认返回最近 **100** 条；可选 **`limit`** 夹在 **1–500**。
3. 服务端筛：**`deviceId`**、**`numericCode`**（子串、不区分大小写）；**`userId`** 按设备表解析的 **owner** 子串匹配；**`consumed`**（**1.41.0**）— **`yes`** = 有 `consumedAt`（已使用），**`no`** = `consumedAt` 为空（未使用）；未知值忽略。
4. 搜索框与 **`?deviceId=`**、**`?userId=`**、**`?numericCode=`**、**`?consumed=yes|no`** URL 同步（可分享链接）。**已消费** 下拉可选 **已消费** / **未使用** / **全部**。
5. 列含配对码、**deviceId**、**userId**（owner）、**sessionId**、**expiresAt**、**consumedAt**。**操作** 列 **设备** → `/devices?deviceId=…`；**用户** → `/users?userId=…`（已知 owner 时）；**会话** → `/sessions?sessionId=…`（**1.40.0**，行有 **sessionId** 时；会话筛与 **`?sessionId=`** URL 同步）。
6. 改码长或 TTL 请到 **系统** 配对策略；被控端仍在 Agent 上生成配对码。

### 用户抽屉与跨模块深链（1.38.0 / 1.42.0）

1. **用户** — 详情抽屉内 **查看会话 / 录制 / 配对 / 订单 / 设备 / 审计** 分别深链到 `/sessions?userId=…`、`/recordings?userId=…`、`/pairings?userId=…`（**1.42.0**；按设备 **owner** 子串筛配对列表）、`/orders?userId=…`、`/devices?ownerId=…`、`/audit?actorId=…`（设备列表按 `ownerId`；抽屉内设备区仍按 owner / org 逻辑展示）。
2. **设备** — 行关联 **活跃会话**（与内存房间匹配）时，**操作** 列 **监控墙** → `/monitor-wall?s0=<sessionId>`（槽位 0 种子；**不是** SFU 多路已交付）。
3. **会话** — 可按 **用户 ID** 筛选；筛选项与 **`?userId=`** URL 同步（用户抽屉「查看会话」会种子此参数）。客户端按行 `userId` 过滤（行无 `userId` 时不匹配）。

### 会员与订单（1.42.0 / 1.43.0）

1. **会员** — 打开 **/membership**（侧栏 **运营管理** → **会员**）。标题旁 **打开订单列表** 在已知 **userId** 时出现，链到 `/orders?userId=…`（**1.42.0**）。
2. **userId 来源** — URL **`?userId=`** 种子；或在本页 **去支付** / **完成支付** 后 commerce 订单响应里的 **userId**（下单或轮询 complete 后写入页面状态）。
3. **订单** — 列表 **`?userId=`** 筛与 URL 同步（与用户抽屉「查看订单」相同参数）；**操作** 列 **会员** → `/membership?userId=…`（订单有 **userId** 时，**1.43.0**）。本页仍以 **local_billing** 列表为主，commerce 单请结合 **会员** 流程理解。
