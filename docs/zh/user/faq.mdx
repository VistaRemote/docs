# 常见问题（用户）

## 配对与连接

**配对码无效？**  
可能已过期（默认约 5 分钟）、输入错误，或已被消费（`PAIRING_CONSUMED`，不能全班共用一码）；被控端重新生成配对码。

**能看画面但不能操作？**  
先确认被控 Agent 已点「允许」，且配对时未勾选「仅观看」。主控端可能未建立控制通道；Win/mac 键鼠注入已实现。刷新会话或联系 IT 检查 Agent 版本。

**一直显示连接中？**  
检查网络、防火墙 UDP，或企业是否配置 TURN 服务器。

**VistaRemote 是 MeshCentral 吗？**  
不是。会话里常用的看屏、键鼠、文件、终端等已收进 VistaRemote；AMT、注册表、远程打印、WOL 等 Mesh RMM 能力不做。对照表见 [远程控制](/user/remote-control)。

## 套餐

**试用结束后无法多人观看？**  
SFU 需要 Pro/Enterprise，见 [套餐与付费](/user/plans-and-billing)。

**开源版可以商用吗？**  
个人非商业免费；**任何商业使用需购买商业授权**，见 [开源协议](/guide/licensing)。

## 隐私与 AI

**数据会发到 OpenAI 吗？**  
默认私有化部署使用 **Ollama + 自建向量库**；云推理仅在启用且有权时使用。

**Desktop 上的 AI 做什么？**  
本地规则/轻量推理用于行为提示；重任务可走队列到 `ai` Worker。

## 管理台与远控运维

**如何强制断开远程会话？**  
打开 [管理控制台](/user/admin-console) → **会话**，对活跃房间执行 **强制断开**。服务端会先关闭信令 WebSocket，再清空内存房间。被控端也可在桌面置顶连接条断开，见 [远程控制](/user/remote-control)。禁用用户不会自动踢掉进行中的会话，仍须在「会话」里断开。

**设备「在线」怎么判定？标签做什么？**  
**在线** = 该设备最近一次心跳大约在 **120 秒**内；超时即离线，不表示正在共享画面。可在「设备」编辑 **标签** 并按标签筛选。吊销设备会让下次心跳失败，与在线判定是两件事。详见 [管理控制台](/user/admin-console)。

**管理台怎么回放录制？是 MinIO 播放器吗？**  
不是。1.11.0 回放是录制页里的 **本机浏览器视频**（`<video>`，支持 seek / 倍速），不是 MinIO 产品播放器。端侧 MediaRecorder 出片与 MinIO 分片上传尚未交付；列表是元数据，不要按云对象播放器验收。

**ICE 卡住要改 DNS 吗？**  
不要先改 DNS。到管理台 **系统** 跑 **ICE 探测**（浏览器 STUN gather），看能否收集到 STUN 候选。探测后可复制探测结果 / STUN URL，便于工单排查。仍失败再查 UDP/防火墙与 TURN，见 [远程控制](/user/remote-control) 连接质量。ICE 由 Server 下发，系统页密钥已掩码。

**权限矩阵可以编辑吗？**  
不能。权限页是 **只读** 对照（平台 RBAC / 组织角色）。**ADM-2**（可编辑角色绑定）尚未交付；不要按可改矩阵做验收。说明见 [管理控制台](/user/admin-console)。

**管理台 CSV 怎么导出？**  
导出的是**当前筛选/已加载的列表**（默认客户端导出，除非该页另有说明；审计 CSV 走服务端筛选，含结果）。用户、设备、安全、任务、订单、组织、录制等页在已实现处有 CSV 按钮；组织详情抽屉内 **SupportGrant** 列表也可 **导出授权 CSV**（1.33.0）。这不是全库/数仓导出，也不是账单/支付导出。说明见 [管理控制台](/user/admin-console)。

**概览卡片和列表筛选能用 URL 打开吗？**  
可以。概览指标卡片和多数列表筛选支持 **URL 查询种子**（例如 `/devices?online=offline`、`/users?planExpiry=expired`、`/audit?result=denied`、`/recordings?status=failed`）。权限矩阵上的搜索只是只读筛选，不是可编辑角色。详见 [管理控制台](/user/admin-console)。

**安全事件的静音规则怎么用？**  
在 [管理控制台](/user/admin-console) → **安全事件** 配置静音类型（告警规则 lite）。列表默认应用已保存规则（Switch「**应用静音规则**」）；关掉或通过 URL `?applyMute=false` 可查看全部类型。高危横幅计数仍排除静音类型。

**SupportGrant 在哪管理？撤销会踢会话吗？**  
组织详情抽屉内 **SupportGrant**：为 IT 协助创建 / 列出 / 撤销临时授权，并可 **导出授权 CSV**（当前筛选/已加载行）。撤销确认框可选「**撤销并断开相关会话**」（`?kickSessions=true`，默认关）。权限矩阵仍只读。详见 [管理控制台](/user/admin-console)。

**系统页的权益标志是什么？**  
**系统** 页只读展示 `entitlementMode`、`entitlementBaseUrlConfigured`、`webhookSecretConfigured` 等标志，**不展示**密钥或 webhook secret；可 **复制权益状态 JSON**（仅上述标志字段，1.33.0）。用于核对 Entitlement 是否配置，不是改套餐入口。见 [管理控制台](/user/admin-console)。

**录制回放 URL 过期怎么办？MinIO EntityTooSmall？**  
录制页播放器经短时签名 **playback-url** 拉流（含 `expiresAt`）；过期可刷新。若 `failedReason` 含 **EntityTooSmall / part size**，列表会提示 Agent 应将非末片合并至 **≥5 MiB**（桌面端 ≥1.30；`memory://` 仍允许小分片）。见 [管理控制台](/user/admin-console)。

**监控墙和完整 SFU 墙有什么区别？**  
当前是 2×2 壳 + 槽位 **墙内旁观**（单路内嵌旁观，FR-WAD-72 MVP），**不是**完整跨会话 SFU 多路监控墙。后者规划为 **FR-WAD-108**（Spec 已定，实现仍开；依赖 SFU multi-producer + MD-4）——不要按已交付验收。见 [管理控制台](/user/admin-console)。

**旁观票据返回什么（1.36.0）？**  
`POST /admin/rooms/:roomId/observe` 返回 shared **AdminObserveTicket** DTO（`signalingTicket`、`role: observe` 等）。SFU 字段（`routerId`、`transport`、`consumer`）当前为 **null 桩** — 尚未接 mediasoup 握手。

**监控墙布局会随改槽位自动保存吗？**  
不会。URL **`s0`–`s3`** 优先；无种子时从 **GET** `/admin/monitor-wall/layout` 恢复；须点 **保存布局**（**PUT**，**admin.write**）才会持久化。见 [管理控制台](/user/admin-console)。

**录制摘要任务怎么跳到录制（1.37.0）？**  
「**任务**」里类型 `recording.summarize`、id 为 `summarize-{recordingId}` 的行，**操作** 列点 **录制** → `/recordings?recordingId=…`。任务筛（`id`、`name`、`state`、`failedReason`）与 URL 同步；概览「失败任务」打开 `/jobs?state=failed`。

**效率报告怎么打开录制列表（1.37.0）？**  
「**效率报告**」点 **打开录制列表** — 把当前 `userId` / `sessionId` / `deviceId` / `recordingId` 子串筛带到 `/recordings`（汇总周期不会传递，仅筛选项）。

**审计 layout 行与监控墙（1.37.0 / 1.38.0）？**  
审计筛 **监控墙 layout**（`admin.monitor_wall.layout`）。**1.38.0** 起 **保存布局** 审计 meta 含 **`roomIds`** 及首个 **`roomId`**。匹配行 **关联** 列 **监控墙** — `/monitor-wall`，或 `/monitor-wall?s0=<roomId>`（meta / resource / target 的 `roomId` / `room_id`）。仅槽位 0 种子；**不是** SFU 多路已交付。见 [管理控制台](/user/admin-console)。

**用户抽屉关联深链怎么用（1.38.0）？**  
「**用户**」打开详情抽屉，点 **查看会话 / 录制 / 订单 / 设备 / 审计** — 分别打开 `/sessions?userId=…`、`/recordings?userId=…`、`/orders?userId=…`、`/devices?ownerId=…`、`/audit?actorId=…`。见 [管理控制台](/user/admin-console)。

**设备怎么从活跃会话跳到监控墙（1.38.0）？**  
「**设备**」行若关联活跃会话，**操作** 列 **监控墙** → `/monitor-wall?s0=<sessionId>`。仅填充槽位 0；**不会**自动发起 SFU 多路或墙内旁观。见 [管理控制台](/user/admin-console)。

**会话怎么按用户 ID 筛选（1.38.0）？**  
「**会话**」可按 **用户 ID** 筛选，并与 **`?userId=`** URL 同步（用户抽屉「查看会话」会种子此参数）。见 [管理控制台](/user/admin-console)。

**管理台哪里看近期配对码（1.39.0）？**  
打开 [管理控制台](/user/admin-console) → **运营管理** → **配对**（`/pairings`）。页面请求 **GET** `/api/v1/admin/pairings`（须 **admin.read**），列出 PostgreSQL 近期配对码（默认 **100** 条；可选 **`limit`** 1–500）。可按设备 ID、owner 用户 ID、配对码筛选，并与 **`?deviceId=`**、**`?userId=`**、**`?numericCode=`** URL 同步。行 **设备** / **用户** 分别打开 `/devices?deviceId=`、`/users?userId=`（设备 owner）。**只读** — 改码长/TTL 请到 **系统** 配对策略；被控端在 Agent 生成配对码。见 [管理控制台](/user/admin-console)。

**系统配对策略与配对行怎么跳转（1.40.0）？**  
**系统** 页 **配对策略** 区 **打开配对** → `/pairings`；**配对** 列表行 **会话** → `/sessions?sessionId=…`（有 sessionId 时）。

**怎么筛已消费配对码？概览/设备怎么进配对（1.41.0）？**  
**配对** 页 **已消费** 下拉（**已消费** / **未使用** / **全部**），与 **`?consumed=yes|no`** 及 **GET** `/api/v1/admin/pairings` 同步（`yes` = 有 `consumedAt`）。也可从 **概览** → **配对** 卡片，或 **设备** → **操作** → **配对**（预填 `?deviceId=`）进入。见 [管理控制台](/user/admin-console)。

**用户抽屉怎么打开配对？会员页怎么打开订单（1.42.0）？**  
「**用户**」详情抽屉 **打开配对列表** → `/pairings?userId=…`；「**会员**」标题旁 **打开订单列表** → `/orders?userId=…`（URL `?userId=` 或本页 commerce 订单 **userId**）。见 [管理控制台](/user/admin-console)。

**订单怎么打开会员？审计怎么筛配对（1.43.0）？**  
「**订单**」**操作** 列 **会员** → `/membership?userId=…`（订单有 **userId** 时；与 1.42.0 会员→订单互为深链）。「**审计**」动作预设含 **`pairing.create`** / **`pairing.join`**（服务端自 1.12.0 起写入）。见 [管理控制台](/user/admin-console)。

**用户端会员页的账单说明在哪（1.43.0）？**  
Web **用户端** `/membership` 页底有灰色脚注：历史订单由平台管理员在管理后台查看 — **页内无管理台链接**。终端用户联系 IT 或销售；运维用管理台 **订单** / **会员**。见 [套餐与付费](/user/plans-and-billing)。
