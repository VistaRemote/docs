# 安装 Agent（用户 / IT）

## 我该装哪个包？

| 您的情况 | 安装包 |
| :--- | :--- |
| 个人远程协助 | **Consumer**（官网下载） |
| 公司要求在自己笔记本上装监控 | **Enterprise BYOD**（IT 提供的链接/门户） |
| 公司配发的办公电脑 | **Enterprise Managed**（通常由 IT 预装，您无需自行下载） |

## 安装后会发生什么？

### Consumer

- 需要您点击「开始共享」才会出现配对码/二维码/链接。
- 每次远程会话通常会再次确认。

### Enterprise BYOD（员工自带）

- 安装后使用 **企业账号登录** 并完成 **同意书**。
- 若公司策略允许，登录后可 **自动上线** 供 IT 监控（无需每次手动点共享）。
- 您仍可卸载软件；公司可能收到告警。

### Enterprise Managed（公司电脑）

- 开机后 Agent 在后台运行，按公司策略 **自动监控**。
- 配对码/二维码可能 **不对员工展示**（仅 IT 远程协助时使用）。
- 卸载通常需要管理员权限。

## 主控如何连接？

IT 或同事向您索取 **数字码**，或扫描您屏幕上的 **二维码**，或打开 **会话链接** — 三种方式等价。详见 [远程控制](/user/remote-control)。

## 合规

所有企业包安装时均会展示 **告知说明**。具体以贵司合同与隐私政策为准。
