# 多机远控工作区

配对成功后进入 **多机控制工作区**（`/control`）。可同时连接多台电脑（上限受套餐会话额度限制，最多 8 台）。

## Viewer 与网页端

日常远控请优先用 **桌面 Viewer**（LAN P2P、后台节流更少、采集权限更稳）。网页 `http://localhost:5173/control` 与 Viewer 共用同一套界面，但浏览器 ICE / 焦点 / 权限常导致键鼠不跟手——适合本机看 UI，不作为主控路径。

## 三种概念（不要混用）

| 名称 | 作用 | 说明 |
| :--- | :--- | :--- |
| **专一** | 视图布局 | 主画面只放大一台；用顶部 Tab 切换其它已连接电脑 |
| **分屏** | 视图布局 | 多台同时预览；点哪台画面，键鼠就打哪台 |
| **同步** | 输入作用域 | 键鼠打到多台（需 Enterprise 群控权益）；与「分屏预览」不是一回事 |

默认：1 台用专一；≥2 台用分屏。可在顶栏手动切换；全部断开后会恢复自动默认。

## 离开后再回来

远控状态保存在页面路由之外。去首页、加机配对页或设置时，**不会自动断开**（除非退出账号、关窗口或点断开）。

- 首页会出现 **返回远控**
- 其它页面顶部有蓝色条 **远控进行中 · 返回**
- 加机页可点 **取消 — 返回远控**

请使用加载了最新 Client 的 Viewer / Web；仅重启 Server 不会更新 Viewer 界面。

## 快捷键

- `Ctrl+1` … `Ctrl+8`（macOS 可用 `Cmd`）：切换到第 1～8 台已连接电脑

## 分屏与带宽

同时打开 3 台及以上完整桌面时，非当前焦点台会优先使用「流畅」画质，以减轻带宽；焦点台保留你在顶栏选择的画质。
