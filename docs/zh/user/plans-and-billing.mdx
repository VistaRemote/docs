# 套餐与付费（用户）

## 套餐概览

| 套餐 | 适用 |
| :--- | :--- |
| **Free / 试用** | 个人或非商业；含限时试用高级能力 |
| **Pro** | 小团队；SFU 多观众、云侧 AI 推理等 |
| **Enterprise** | 审计、策略、私有化部署、专属支持 |

权威定义见 [商业化与试用](/architecture/commercial-trial) 与 `spec/commercial-tier-spec.md`。

## 试用结束后

以下能力在试用结束后通常需要 **付费套餐**：

- **SFU** 多观众（一人共享、多人观看）
- **云端行为推理**（`behavior.cloud_infer`）
- **云录制与回放**（`recording` — 端侧缓冲上传，不占 SFU 录制资源）

端侧规则推理（Desktop 本地）在符合授权的前提下仍可使用。

## 录制怎么计费？

| 能力 | 套餐 | 说明 |
| :--- | :--- | :--- |
| **端侧录制 + 云存储** | Pro+ | 在被控电脑本地缓冲，分片上传；**不在 SFU 上默认录制** |
| **SFU 中心录制** | Enterprise | PlainTransport + FFmpeg，资源占用高，单独功能点 |

详见 [录制与商业化资源点](/architecture/recording-and-billing)。

## 购买方式

- **订阅**：按月/年续费
- **买断**：一次性永久授权（以产品目录为准）

支付渠道（部署相关）：微信支付、支付宝、PayPal、Wise 等 — 以贵司实例启用的为准。

## 升级与续费

1. 登录 Web 用户端或联系销售获取订单链接。
2. 完成支付后权益自动生效（生产环境需支付回调；开发环境可能为模拟支付）。
3. 到期前续费可避免 SFU / 云推理被拦截。

开发者集成见 [商业化与计费](/architecture/commercial-billing)。
