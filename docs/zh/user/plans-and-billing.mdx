# 套餐与付费（用户）

## 套餐概览

| 套餐 | 适用 |
| :--- | :--- |
| **Free / 试用** | 个人或非商业；含限时试用高级能力 |
| **Pro** | 小团队；SFU 多观众、云侧 AI 推理等 |
| **Enterprise** | 审计、策略、私有化部署、**设备舰队**（群控 / 监控墙 / 虚拟屏等）、专属支持 |

权威说明见 [商业化与试用](/architecture/commercial-trial)。

## 企业舰队能力（Enterprise）

购买企业服务后可开通（详见 [设备舰队与企业能力](/user/fleet-and-enterprise)）：

| 能力 | 说明 |
| :--- | :--- |
| **群控键鼠** | 一台主控同步操作多台已授权设备 |
| **批量命令** | 通知、锁屏、重启、打开链接等 |
| **多屏监控墙** | 缩略图低成本观察，点选进入高质量远控；更大槽位可合同加购 |
| **虚拟显示器** | 远控专用虚拟屏，减少打扰本机桌面 |
| **带外管理（AMT 等）** | 企业私有化场景按合同开通 |

购买企业服务后开通。更大的监控墙槽位和现场范围写在合同里。详见 [设备舰队与企业能力](/user/fleet-and-enterprise)。

## 试用结束后

以下能力在试用结束后通常需要 **付费套餐**：

- **多人观看**（一人共享、多人同时看）
- **云端行为分析**
- **云端录制与回放**（在被控电脑本地缓冲后上传，不占用多人观看那条链路的录制资源）

端侧规则推理（Desktop 本地）在符合授权的前提下仍可使用。

## 录制怎么计费？

| 能力 | 套餐 | 说明 |
| :--- | :--- | :--- |
| **端侧录制 + 云存储** | Pro 及以上 | 在被控电脑本地缓冲，分片上传；默认不在多人观看的转发服务上录制 |
| **中心录制** | Enterprise | 在转发服务侧录制，资源占用更高，单独开通 |

详见 [录制与商业化资源点](/architecture/recording-and-billing)。

## 购买方式

- **订阅**：按月/年续费
- **买断**：一次性永久授权（以产品目录为准）

支付渠道按部署启用：微信支付、支付宝、PayPal、Wise、银行卡。

## 升级与续费

1. 登录 Web 用户端，或向销售要支付链接。
2. 支付完成后套餐生效。管理员也可以在管理台直接调整用户套餐。
3. 到期前续费，多人观看和云端分析不会中断。

## 用户端会员页

在 Web 用户端的会员页选择微信支付或支付宝，按二维码或支付链接完成付款。页面会等待支付结果，也可以点完成支付以刷新套餐。历史订单在管理台查看，会员页本身不跳到管理台。

## 给运维与实施

- 生产环境的支付回调在 Entitlement。上线前按 [生产支付就绪](/user/payment-production) 核对。
- 本地或沙箱环境：用户端会员页会轮询订单；管理台可以对 **本地订单** 做模拟支付，用来开通套餐。这不代替生产商户的到账通知。
- 渠道在界面上显示为微信、支付宝等名称。对接时的渠道标识不要展示给终端用户。

开发者集成见 [商业化与计费](/architecture/commercial-billing)。
