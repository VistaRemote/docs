## 2. 架构速览

- **Meta-Repo**：`shared` → `server` / `ai` → `web` / `desktop` / `mobile`
- **契约**：跨端类型只在 `shared` 定义
- **信令**：WSS `/signaling` + 可选 SSE 通知
- **媒体**：WebRTC P2P；多观众走 SFU（需套餐权益）

详见 [架构总览](/architecture/overview)。

## 3. 新增功能（标准流程）

```text
1. 查 implementation-status → 确认依赖已 Ready
2. 在对应 spec/*.md 写 FR-xxx + 验收标准
3. 改 shared（若跨端）
4. 实现 server / 客户端
5. 单测 + 手测
6. 更新 implementation-status + 用户文档（若可见）
```

分步说明：[功能开发指南](/guide/feature-development)。

## 4. 常用仓库命令

| 仓库 | 开发 |
| :--- | :--- |
| `server` | `pnpm start:dev` |
| `web` client | `pnpm --filter @vistaremote/web-client dev` |
| `web` admin | `pnpm --filter @vistaremote/web-admin dev` |
| `desktop` | `pnpm dev` |
| `shared` | `pnpm build`（改契约后先 build） |

## 5. 跨库 PR 顺序

1. `shared` 合并
2. 各消费者拉取 / bump
3. 业务仓 PR（**同名分支** `feat/xxx`）

见 [Git 工作流](/engineering/git-workflow) 与 `spec/git-collaboration-spec.md`。
