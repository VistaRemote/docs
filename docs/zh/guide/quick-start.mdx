# 快速开始

## 环境要求

- **Git**
- **Node.js** >= 22.0.0（推荐 **24.11 LTS**，Meta-Repo 根目录执行 `nvm use`）
- **pnpm** >= 9

## 新成员（推荐路径）

```bash
git clone git@github.com:VistaRemote/vista-remote.git
cd vista-remote
nvm use
./init.sh          # Windows: .\init.ps1
./dev.sh           # Windows: .\dev.ps1
```

打开 `vista-remote.code-workspace`，按 [本地开发与多环境切换](/guide/local-development) 启动 server / web / desktop / mobile。

## 仅文档站

```bash
cd docs
pnpm install
pnpm dev
```

浏览器打开终端提示的地址（默认 `http://localhost:13401`）。
