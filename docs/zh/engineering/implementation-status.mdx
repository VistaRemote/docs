# 平台组成

VistaRemote 由一组职责清晰的组件组成。信令与业务在服务端，画面与键鼠走 WebRTC，类型契约统一在 `shared`，AI 推理独立部署。

## 组件

| 组件 | 职责 |
| :--- | :--- |
| `shared` | 信令、认证、计费、遥测与 AI 任务的类型契约 |
| `server` | NestJS 信令、会话、权益与管理 API |
| Web 主控 | 浏览器远控、播放与套餐能力 |
| 管理台 | 用户、设备、订单、会话、录制与审计 |
| `desktop` | Windows / macOS Agent 与桌面主控 |
| `mobile` | 手机主控 |
| `ai` | 会话摘要、行为洞察与私有化模型 |
| `deploy` | Docker Compose 与 mediasoup |
| 文档 | 中英产品与开发文档 |

## 数据与实时

- **PostgreSQL** 保存用户、设备、会话、订单与审计。
- **WebSocket** 交换 SDP / ICE；**SSE** 推送业务通知。
- **一对一** 走 P2P；**一对多观摩** 走 SFU，被控端只上行一路。
- 录制对象放在 **MinIO / S3**。
