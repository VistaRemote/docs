# Docker 部署

## 组件清单

| 服务 | 说明 |
| :--- | :--- |
| **postgres** | PostgreSQL 16（**唯一**关系型 OLTP；宿主机 **:5436**） |
| **redis** | 会话、BullMQ |
| **minio** | Pro+ 录制对象存储 |
| **server** | NestJS API + 信令 |
| **ai** | AI Worker（内网） |
| **coturn** | TURN/STUN |
| **web-client** / **web-admin** | 静态资源 |

> 与 **LuminaryWorks** 生态一致，全栈使用 **PostgreSQL** 作为唯一 OLTP。

## 快速开始（规划）

```bash
cd deploy
cp compose/.env.example compose/.env
# 编辑 PostgreSQL、JWT、MinIO、AI 等变量
docker compose -f compose/docker-compose.dev.yml up -d
```

具体 Compose 文件见 `deploy/compose/`；规格见 Meta-Repo `spec/deploy-spec.md` 与 [ADR-0008](https://github.com/VistaRemote/vibeCode/blob/main/adr/0008-postgresql-oltp.md)。

## 防火墙

- TCP：443（HTTPS）、3000（API，可内网）
- UDP：3478（TURN）、SFU 端口段（按配置文档）

## 私有化 LLM

Enterprise 可将 `AI_BASE_URL` 指向内网 **Ollama**，无需公网 LLM。参见 [产品定位](/architecture/positioning)。
