# Docker Deployment

Planned stack (`deploy` repo):

- **PostgreSQL 16** (only relational DB)
- Redis, MinIO, server, ai, coturn
- web-client & web-admin static sites

PostgreSQL 16 is the **only** relational OLTP database (aligned with LuminaryWorks).

```bash
cd deploy
cp compose/.env.example compose/.env
docker compose -f compose/docker-compose.yml up -d
```

See Meta-Repo `spec/deploy-spec.md` for requirements.
