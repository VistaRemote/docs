# Local AI dev (private stack)

Debug **behavior analytics + self-hosted LLM + vector DB + Python ML** without public API keys.

Requires the **core + dev** layers; AI services are on the dev overlay **`ai`** profile (opt-in).

## Start stack

```bash
cd deploy
cp compose/.env.example .env

# baseline (postgres, redis, server)
docker compose -f compose/docker-compose.core.yml -f compose/docker-compose.dev.yml up -d

# Ollama + Qdrant + python-worker
docker compose -f compose/docker-compose.core.yml -f compose/docker-compose.dev.yml --profile ai up -d
```

| Service | URL |
| :--- | :--- |
| PostgreSQL | `localhost:5637` |
| Redis | `localhost:6380` |
| Ollama (LLM) | `http://localhost:11435` |
| Qdrant | `http://localhost:6335` |
| python-worker | `http://localhost:4100` |

Host ports **11435** / **6335** avoid clashes with VistaCast defaults (`11434` / `6333`).

```bash
docker compose -f compose/docker-compose.core.yml -f compose/docker-compose.dev.yml exec ollama ollama pull llama3.2
```

## Run apps

```bash
cd shared && pnpm install && pnpm build
cd server && pnpm install && pnpm start:dev
cd ai && cp .env.example .env && pnpm install && pnpm start:dev
```

`ai/.env`:

```ini
REDIS_URL=redis://localhost:6380
AI_BASE_URL=http://localhost:11435/v1
AI_MODEL=llama3.2
VECTOR_DB_URL=http://localhost:6335
PYTHON_ML_URL=http://localhost:4100
```
