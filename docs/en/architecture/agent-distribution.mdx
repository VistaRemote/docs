# Agent Distribution & Access

Canonical spec: Meta-Repo `spec/agent-distribution-spec.md`.

## Controller entry points

| Method | Description |
| :--- | :--- |
| **Numeric code** | 6–8 digits, short TTL |
| **QR code** | Encodes `linkToken` or full URL |
| **Link** | `https://<site>/join/{token}` or `vistaremote://join?token=` |

Web client: `/pairing` (tabs), `/join/:token` (deep route).

## Three installer variants

| Package | Scenario | Default behavior |
| :--- | :--- | :--- |
| **Consumer** | Personal install | Interactive consent each session |
| **Enterprise BYOD** | Employee-owned PC, voluntary install | Auto-monitor after enrollment + consent |
| **Enterprise Managed** | Company PC, MDM/GPO | Policy-driven; pairing UI may be hidden |

Build: `node tooling/scripts/build-agent-packages.mjs all`

## APIs (dev)

- `POST /api/v1/devices/pairing-session`
- `POST /api/v1/auth/pairing`
- `POST /api/v1/devices/register` with `installChannel`
