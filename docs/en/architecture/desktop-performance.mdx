# Desktop Performance Architecture

Normative: `spec/desktop-performance-spec.md` · `desktop/ARCHITECTURE.md`.

## Goals

1. **No video over IPC** — `MediaStream` into WebRTC.  
2. **GPU first** — NVENC / Intel QSV where available.  
3. **Electron is the console** — capture, encode, and recording run in a **local Agent service**.  
4. **Performance stays native** — capture, encode, and recording run in the local Agent service. Detail is in `spec/desktop-performance-spec.md`.

## Approach

| Area | Approach |
| :--- | :--- |
| Capture | MediaStream pipeline |
| Encode | Hardware acceleration |
| Recording | Agent-side buffer + chunked cloud upload |
| Web / Mobile | WebCodecs, native video surfaces |

Contributors: see `spec/desktop-performance-spec.md` in the Meta-Repo.
