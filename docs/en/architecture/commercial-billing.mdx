# Orders, subscriptions, and client-side gates

## Purchase types

| Type | Description |
| :--- | :--- |
| **Subscription** | Monthly or **yearly (~15% off)**; expires at `planExpiresAt` |
| **Perpetual** | One-time purchase for the tier |

SKU catalog: `shared/src/billing/catalog.ts`.

## Trial and enforcement

Same as [Trial and paid features](./commercial-trial): **SFU** and **cloud AI** require payment after trial.

| Tier | Enforcement |
| :--- | :--- |
| Server | Signaling blocks extra viewers; cloud infer jobs skipped |
| Web | `FeatureGate` + entitlements API |
| Desktop | `assertCloudInferAllowed` before cloud placement |
| Mobile | `fetchEntitlements` / `canUseSfu` |

## Payment providers

WeChat, Alipay, PayPal, Stripe, and bank card are supported. After the person pays on the Web membership page, the plan is written onto the user and shows up in the admin user list. Merchant secrets stay in Entitlement, not in the client. The UI shows channel names such as WeChat and Alipay.

**System** in the admin console shows whether the entitlement service is connected, without revealing secrets. Production checks: [Production payment readiness](/user/payment-production).
