# Orders, subscriptions, and client-side gates

## Purchase types

| Type | Description |
| :--- | :--- |
| **Subscription** | Monthly or **yearly (~15% off)**; expires at `planExpiresAt` |
| **Perpetual** | One-time purchase for the tier |

SKU catalog: `shared/src/billing/catalog.ts`.

## Trial and enforcement

Same as [Trial and paid features](./commercial-trial): **SFU** and **cloud AI** require payment after trial.

| Tier | Enforcement |
| :--- | :--- |
| Server | Signaling blocks extra viewers; cloud infer jobs skipped |
| Web | `FeatureGate` + entitlements API |
| Desktop | `assertCloudInferAllowed` before cloud placement |
| Mobile | `fetchEntitlements` / `canUseSfu` |

## Payment providers

Central Entitlement ships WeChat / Alipay / PayPal / Stripe / etc. **adapters** (sandbox-tested); **live merchant enablement** (credentials, notify DNS, `enabled=true`) is owner-ops — not shipped with VistaRemote. Bank cards later.

Dev: owner `POST /api/v1/billing/orders/:id/simulate-paid`. With `ENTITLEMENT_MODE=enforce`, WeChat/Alipay go through Entitlement sandbox (`wechat`→`wechat_pay_v3`, `alipay`→`alipay_f2f`); no production secrets in git. Admin orders are `local_billing` only. **1.27.0**: Client Membership checkout uses catalog **`providerHint`** (`wechat` / `alipay`); the BFF maps to Entitlement adapters — do not surface adapter ids in the UI. **1.28.0**: after commerce payment, the client polls **complete** and syncs local **User.plan** so the Admin Users list reflects the tier immediately without production webhook delay. **1.29.0**: lite `POST /api/v1/commerce/webhooks/entitlement` (`x-lw-signature: v1=<base64url>`; HMAC `${timestamp}.${nonce}.${rawBody}`; legacy `X-Entitlement-Signature` hard-cut 401) also syncs **User.plan**; not production WeChat/Alipay PSP. **1.30.0**: Admin System page shows read-only `entitlementMode` / `baseUrlConfigured` / `webhookSecretConfigured` (no secret values). Production checklist (mock → sandbox → production; env **names only**; bad-signature 401; commerce simulate-paid forbidden): [Production payment readiness](/user/payment-production). WeChat/Alipay merchant onboarding is owner-ops, not shipped.
