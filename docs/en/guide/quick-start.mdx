## Meta-Repo

```bash
git clone git@github.com:VistaRemote/vista-remote.git
cd vista-remote
chmod +x init.sh
./init.sh
```

## Documentation site

```bash
cd docs
pnpm install
pnpm dev
```

Open the URL printed in the terminal (default `http://localhost:5173`).

## Local dev (recommended)

```bash
./dev.sh    # Windows: .\dev.ps1
```
