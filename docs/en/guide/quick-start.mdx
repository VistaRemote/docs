## Prerequisites

- Git
- Node.js >= 24 (recommended **24.11 LTS** — run `nvm use` at the Meta-Repo root)
- pnpm >= 11

## Meta-Repo

```bash
git clone git@github.com:VistaRemote/vista-remote.git
cd vista-remote
chmod +x init.sh
./init.sh
```

## Documentation site

```bash
cd docs
pnpm install
pnpm dev
```

Open the URL printed in the terminal (default `http://localhost:13401`).

## Local dev (recommended)

```bash
./dev.sh    # Windows: .\dev.ps1
```

See [Developer handbook](/guide/developer-handbook).
