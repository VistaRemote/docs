# Pairing

1. **Agent** shows a pairing code after user consent.
2. **Controller** (Web or mobile) submits the code to the server.
3. Signaling over WebSocket exchanges SDP/ICE.
4. Media flows over **WebRTC P2P** (or **SFU** for multiple viewers).

See [WebRTC topology](/architecture/webrtc-topology) for details.
