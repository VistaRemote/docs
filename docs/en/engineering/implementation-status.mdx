# Platform

VistaRemote is a set of components with clear jobs. Signaling and business APIs live on the server, picture and input travel over WebRTC, types live in `shared`, and AI inference runs on its own service.

## Components

| Component | Role |
| :--- | :--- |
| `shared` | Contracts for signaling, auth, billing, telemetry, and AI jobs |
| `server` | NestJS signaling, sessions, entitlements, and admin APIs |
| Web controller | Browser remote control, playback, and plan features |
| Admin console | Users, devices, orders, sessions, recordings, and audit |
| `desktop` | Windows / macOS Agent and desktop controller |
| `mobile` | Phone controller |
| `ai` | Session summaries, behavior insight, and private models |
| `deploy` | Docker Compose and mediasoup |
| Docs | Chinese and English product and developer docs |

## Data and realtime

- **PostgreSQL** stores users, devices, sessions, orders, and audit.
- **WebSocket** carries SDP / ICE; **SSE** carries product notifications.
- **One-to-one** uses P2P; **one-to-many viewing** uses an SFU so the host uploads once.
- Recordings go to **MinIO / S3**.
