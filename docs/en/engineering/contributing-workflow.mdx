# Contributing Workflow

1. Read [DEVELOPMENT.md](https://github.com/VistaRemote/vista-remote/blob/main/DEVELOPMENT.md) and [Implementation status](/engineering/implementation-status).
2. Update Spec + `shared` before feature code (see [Spec-driven development](/guide/spec-driven-development)).
3. Use Conventional Commits; cross-repo features share one branch name.
4. Open PRs per repository; link FR-xxx and touched repos in the Meta-Repo PR template.

Full guide: [CONTRIBUTING.md](https://github.com/VistaRemote/vista-remote/blob/main/CONTRIBUTING.md).
