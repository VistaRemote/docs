# FAQ (Users)

## Pairing & connection

**Invalid pairing code?**  
It may have expired (~5 minutes by default) or was mistyped; regenerate on the host.

**Video works but no control?**  
Control channel may be missing; refresh the session or check Agent version with IT.

**Stuck on connecting?**  
Check network/firewall UDP and whether TURN is configured.

## Plans

**Cannot multi-view after trial?**  
SFU requires Pro/Enterprise — see [Plans & billing](/user/plans-and-billing).

**Can I use the open-source build commercially?**  
Free for personal non-commercial use; **all commercial use requires a paid license** — see [Licensing](/guide/licensing).

## Privacy & AI

**Is data sent to OpenAI by default?**  
Default private deployment uses **Ollama + self-hosted vector DB**; cloud inference only when enabled and entitled.

**What does Desktop AI do?**  
Local rules/light inference for behavior hints; heavy jobs go to the `ai` worker queue.
