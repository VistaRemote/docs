# Admin console

For **enterprise IT and administrators**. Manage users, devices, sessions, recordings, orders, and compliance data in one console.

## Access

- The URL is provided by whoever deploys the product, usually `https://<your-domain>/admin`
- Sign in as a **platform admin** or an **organization admin**

## Modules

| Module | What it does |
| :--- | :--- |
| **Overview** | Counts for organizations, users, online devices, sessions, unpaid orders, failed recordings, and failed jobs, with links into the matching lists |
| **Users** | View, filter, create, and disable accounts; assign organization and plan; open that person’s sessions, recordings, pairings, orders, devices, and audit; export CSV |
| **Devices** | Online / offline (a heartbeat within about 120 seconds counts as online), owner, organization, and label filters; edit labels and revoke devices; open the monitor wall when a session is active; export CSV |
| **Pairings** | Recent pairing codes, filtered by device, user, code, and whether the code was used, with links to the device, user, or session |
| **Sessions** | P2P / SFU rooms; force-disconnect or observe; filter by user; export CSV |
| **Recordings** | Filter by user, device, status, session, and trigger; play back in the browser (seek and speed); export CSV |
| **Audit** | Filter by actor, action, time, resource, and result (ok / denied / error); monitor-wall layout changes link back to the wall; export CSV |
| **Security events** | Exfiltration, bulk delete, and similar risks; filter by type, device, user, and organization; mute event types; jump to the related session, device, or recording |
| **Organizations** | Organizations, seats, and member roles; temporary IT assist grants (create, list, revoke, and optionally disconnect related sessions); export members and grants as CSV |
| **Orders** | Plan orders by user, SKU, payment provider, and status, with a link to that user’s membership |
| **Membership** | People pay with WeChat, Alipay, or another enabled provider on the Web client; the plan is written onto the user and shows up in the admin user list |
| **System** | See whether entitlements and payments are configured (no secrets), copy ICE / TURN and pairing policy, and open the pairings list |
| **Jobs** | Background work such as recording summaries; filter by status and retry failures; a summary job links to its recording |
| **Efficiency reports** | Recording minutes by week or month, with filters that open the recordings list |
| **Permissions** | Read the platform and organization permission matrix; assign platform operators and organization member roles; export CSV |
| **Monitor wall** | Thumbnail observation across many screens, then click through to high-quality control; layouts can be saved. Enterprise — see [Device fleet and enterprise](/user/fleet-and-enterprise) |

List filters are stored in the URL, so overview cards and shared links open the same view.

## Common tasks

### Give someone a plan

1. Change the plan on **Users**.
2. Or have the person open membership on the Web client and pay with WeChat or Alipay. After payment, the user list shows the new plan.
3. After a refresh or a new sign-in, remote control, recording, and AI entitlements apply.

### Disable a user

1. Disable the account in the user list.
2. That person cannot start a new remote session. Disconnect any session already in progress from **Sessions**.

### Monitor wall

1. Open the monitor wall and place active sessions in slots.
2. **Save layout** (write permission required). The next visit restores it. The URL can also pre-fill slots.
3. Thumbnails are for watching the floor. Click a tile to enter the control session.

Larger walls are enabled under the enterprise contract. See [Device fleet and enterprise](/user/fleet-and-enterprise).

### Look up a pairing code

Open **Pairings** and filter by device, user, or code. Code length and lifetime are set under pairing policy on **System**. The Agent on the host still creates the code.

### Follow one person across records

Open a user and jump to their sessions, recordings, pairings, orders, devices, and audit. If a device has a live session, open it on the monitor wall.

## Enterprise scope

Group control, larger monitor walls, configurable alert policy, and production WeChat / Alipay merchants are enabled with Enterprise and the contract. See [Device fleet and enterprise](/user/fleet-and-enterprise).

## Security

The admin console runs on your server and signs in with the shared account. It does not have to sit on a private network.

- **Registration**: the first sign-up verifies the email address. Later sign-ins use email and password, without a code every time.
- **Optional one-time codes**: a person can bind an authenticator on the account. Microsoft Authenticator works. It reads a standard one-time code, and the app is free — no paid Microsoft plan is required. Other authenticator apps work too. Sign-in still works if they skip this.
- **When an organization requires it**: that organization can require members to complete the step.
- Review disable-user, plan changes, force-disconnect, and device revoke in **Audit**, and export when you need a copy.

## Payments

| Path | What happens |
| :--- | :--- |
| Admin changes the plan | Set the plan on **Users** |
| The person pays | Membership on the Web client (WeChat, Alipay, or another enabled provider) writes the plan after payment |
| Entitlement status | **System** shows whether the entitlement service is connected, without revealing secrets |
