## Access

- URL is typically `https://<your-domain>/admin` (provided by your operator)
- Sign in with a **platform admin** or **org admin** account

## Modules

| Module | Purpose |
| :--- | :--- |
| **Overview** | Live count cards, including **org count** and **pending orders**, plus users, sessions, recordings, devices / online devices, and similar |
| **Users** | View / filter (including **user ID** and **org ID**) / create / disable accounts; assign org and plan; export **CSV** |
| **Devices** | Agent **online** status (heartbeat within about 120 seconds), **online / offline**, **owner / org**, and **label** filters, label edit, revoke device; export **CSV** (overview **Online devices** deep-links to the online filter) |
| **Sessions** | Active remote rooms (p2p / SFU); admins can **force disconnect** / **observe** (single stream); list is filterable; export **CSV** |
| **Recordings** | **Filter** by user, **recording ID**, **device ID**, status, session, and trigger; export **CSV**; built-in player fetches a **playback-url** short-lived signed stream (`expiresAt`, refresh on expiry; in-memory `/media`); **seek** and **playback speed** |
| **Audit** | **Filter** by actor, action presets, time, resource / **resource type**, and **result** (`ok` / `denied` / `error`); export **CSV** |
| **Security events** | Exfiltration risk, bulk delete, behavior inference, and similar; filter by type, **deviceId**, **userId**, and **orgId**, high-severity banner; jump to a related recording timestamp / **session / device**; export **CSV** |
| **Organizations** | Orgs, seats/members, and policy (keywords, domains, and similar); change member **orgRole**; drawer **SupportGrant** (IT-assist) create / list / revoke; list **CSV**; detail **members CSV** |
| **Orders** | Filter plan orders by user, SKU, **provider**, **source (`local_billing`)**, and status; export **CSV**. This list is **local billing**, not Entitlement commerce. Dev-only **simulate paid** applies to local pending rows. Do **not** use an Admin JWT against `/billing/.../simulate-paid` or to pay someone else's commerce order. |
| **System** | Read-only ICE/TURN status (secrets masked); browser **ICE probe** and **copy probe result**; pairing-code policy |
| **Jobs** | Background jobs (for example recording summaries): list; filter by **id / name / state**; retry failed jobs; export **CSV** |
| **Efficiency reports** | Weekly / monthly recording-minute totals; filter by **userId / sessionId** before rollup (from recording metadata, not an LLM efficiency model); export **CSV** |
| **Permissions** | Platform / org permission matrices are **read-only**; export reference **CSV**; assign **platform operator** roles (not checkbox Permission edits) |
| **Monitor wall** | 2×2 session placeholder shell; slots deep-link to observe; multi-stream SFU wall is later |

## Common tasks

### Grant Pro to a user

1. Production: Entitlement **sandbox** WeChat / Alipay (see below), or assign the plan in **Users** after your contract workflow.
2. Dev shortcut: the owner calls `POST /api/v1/billing/orders/:id/simulate-paid` with a **Controller JWT** (their **local** order only). Admin **Simulate paid** is local `source=local_billing` only — it does **not** pay commerce orders.
3. User refreshes the client or signs in again.

### Disable a user

1. Users → select user → disable.
2. The user cannot start new sessions. For an active session, open **Sessions** and **force disconnect**.

## Not in this release

Do not treat the following as delivered:

- Agent **MediaRecorder** capture and a **MinIO** product player (you get a metadata list plus simple speed/seek playback)
- An **editable permission matrix** (the Permissions page is a read-only reference)
- A multi-stream **monitor wall**
- Production **WeChat Pay / Alipay** secrets (never commit them; sandbox lives on Entitlement)

Remaining gaps: [Implementation status](/engineering/implementation-status).

## Security

- Prefer VPN or a private network for the admin URL; MFA is planned (P1).
- Audit sensitive actions (disable user, plan changes, force disconnect, device revoke); filter and export CSV as needed.

## Payments and Entitlement (mock → sandbox)

| Mode | Behavior |
| :--- | :--- |
| `ENTITLEMENT_MODE=off` (default) | Local plan/orders; no central Entitlement |
| `ENTITLEMENT_MODE=enforce` | Entitlement is authoritative for commercial checkout |
| Mock / dev | Owner `POST /api/v1/billing/orders/:id/simulate-paid` (local order) |
| Sandbox WeChat / Alipay | `POST /api/v1/commerce/orders/:id/pay`; `wechat`→`wechat_pay_v3`, `alipay`→`alipay_f2f`; secrets only in Entitlement env |
