# Admin Console (Users)

For **enterprise IT / administrators** managing users, devices, sessions, and compliance data.

As of **1.11.0**, the modules below use live server data, not demo data. **1.13.0** adds **CSV export** on orders, organizations, and recordings (users, devices, security events, and jobs already had it); **online / offline** device filter; audit **result** filter (`ok` / `denied` / `error`); security-event **deviceId** filter; and dashboard **org count** plus **pending orders**. **1.14.0** adds sessions / permissions-matrix **CSV**; user **org ID** filter; efficiency-report **userId / sessionId** filters; jobs **id** filter; and audit **resource type** filter. Roles: [Authorization](/architecture/authorization).

## Access

- URL is typically `https://<your-domain>/admin` (provided by your operator)
- Sign in with a **platform admin** or **org admin** account

## Modules

| Module | Purpose |
| :--- | :--- |
| **Overview** | Live count cards, including **org count** and **pending orders**, plus users, sessions, recordings, devices / online devices, and similar |
| **Users** | View / filter (including **org ID**) / create / disable accounts; assign org and plan; export **CSV** |
| **Devices** | Agent **online** status (heartbeat within about 120 seconds), **online / offline** and **label** filters, label edit, revoke device; export **CSV** |
| **Sessions** | Active remote rooms (p2p / SFU); admins can **force disconnect**; list is filterable; export **CSV** |
| **Recordings** | **Filter** by user, status, session, and trigger; export **CSV**; built-in player with **seek** and **playback speed** |
| **Audit** | **Filter** by actor, action presets, time, resource / **resource type**, and **result** (`ok` / `denied` / `error`); export **CSV** |
| **Security events** | Exfiltration risk, bulk delete, behavior inference, and similar; filter by type and **deviceId**, high-severity banner; jump to a related recording timestamp; export **CSV** |
| **Organizations** | Orgs, seats/members, and policy (keywords, domains, and similar); export **CSV** |
| **Orders** | Filter plan orders by user, SKU, and status; export **CSV** (entitlements are still applied by changing the plan; no live checkout) |
| **System** | Read-only ICE/TURN status (secrets masked); browser **ICE probe**; pairing-code policy |
| **Jobs** | Background jobs (for example recording summaries): list; filter by **id / name / state**; retry failed jobs; export **CSV** |
| **Efficiency reports** | Weekly / monthly recording-minute totals; filter by **userId / sessionId** before rollup (from recording metadata, not an LLM efficiency model); export **CSV** |
| **Permissions** | Platform / org permission matrices are **read-only**; export reference **CSV** (role bindings are not editable) |

## Common tasks

### Grant Pro to a user

1. Confirm payment or your internal contract workflow (this release has **no** live WeChat Pay / Alipay checkout; entitlements are applied by changing the plan).
2. In **Users**, set the account plan to `pro` with a valid expiry.
3. User refreshes the client or signs in again.

### Disable a user

1. Users → select user → disable.
2. The user cannot start new sessions. For an active session, open **Sessions** and **force disconnect**.

## Not in this release

Do not treat the following as delivered:

- Agent **MediaRecorder** capture and a **MinIO** product player (you get a metadata list plus simple speed/seek playback)
- An **editable permission matrix** (the Permissions page is a read-only reference)
- A multi-stream **monitor wall**
- Live **WeChat Pay / Alipay** checkout

Remaining gaps: [Implementation status](/engineering/implementation-status).

## Security

- Prefer VPN or a private network for the admin URL; MFA is planned (P1).
- Audit sensitive actions (disable user, plan changes, force disconnect, device revoke); filter and export CSV as needed.
