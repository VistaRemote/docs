# Plans & Billing (Users)

## Plan overview

| Plan | For |
| :--- | :--- |
| **Free / trial** | Personal or non-commercial; time-limited premium trial |
| **Pro** | Small teams; SFU multi-viewer, cloud AI inference, etc. |
| **Enterprise** | Audit, policies, self-hosted, **device fleet** (group control / monitor wall / virtual display, etc.), dedicated support |

Canonical rules: [Commercial trial](/architecture/commercial-trial) and `spec/commercial-tier-spec.md`.

## Enterprise device fleet

After purchasing enterprise service (see [Device Fleet & Enterprise](/user/fleet-and-enterprise)):

| Capability | Notes |
| :--- | :--- |
| **Group keyboard & mouse** | One controller operates many authorized devices |
| **Batch commands** | Notify, lock, reboot, open URL, and more |
| **Multi-screen monitor wall** | Thumbnail observe, click-up to HD control; larger slots as contract add-on |
| **Virtual display** | Dedicated virtual screen for remote sessions |
| **Out-of-band (AMT, etc.)** | Enabled under enterprise private-deploy contracts |

Proposals may state these as **supported product capabilities**; enablement and on-site delivery follow sales / implementation and the contract.

## After trial ends

These typically require a **paid plan**:

- **SFU** multi-viewer
- **Cloud behavior inference** (`ai.cloud_infer`)
- **Cloud recording & playback** (`recording` — agent-side buffer upload)

## Recording & plans

| Capability | Plan | Notes |
| :--- | :--- | :--- |
| Agent-side recording + cloud storage | Pro+ | Local buffer, chunked upload; **not** default SFU recording |
| SFU server recording | Enterprise | PlainTransport + FFmpeg; high resource use |

See [Recording & billing](/architecture/recording-and-billing).

## Purchase options

- **Subscription**: monthly/yearly renewal
- **Perpetual**: one-time license (per product catalog)

Payment methods depend on deployment: WeChat Pay, Alipay, PayPal, Wise, etc.

## Upgrade & renewal

1. Sign in to the web client or contact sales for checkout.
2. Entitlements apply after successful payment (sandbox: Client Membership poll / complete; production webhooks land on Entitlement). Dev may simulate **local** orders in Admin. Ops go-live checklist: [Production payment readiness](/user/payment-production).
3. Renew before expiry to avoid SFU / cloud inference being blocked.

## Client membership page (1.43.0 / 1.52.0)

Web **Client** `/membership`: pick catalog `providerHint` (WeChat Pay / Alipay), show QR or a payment link, then **poll order status** and optionally **Complete payment**. The on-page sandbox note is **not** live merchant notify. A muted footnote says past orders are for platform operators in **Admin**. There is **no Admin link** on that page. Operators use [Admin console](/user/admin-console) **Users** (plan grant) or **Orders** (local simulate-paid only).

Integrators: [Commercial billing](/architecture/commercial-billing).
