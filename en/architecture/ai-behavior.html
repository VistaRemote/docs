      #AI behavior insights architecture

      VistaRemote Enterprise adds monitoring, alerts, and efficiency insights on remote desktop. Data stays in customer-controlled infrastructure (Ollama + Qdrant + PostgreSQL)—no default dependency on public LLM APIs.

      #Multi-model split

      TypeExamplesWhere it runs
      Real-time detectionSmall models, CV, time-seriesDesktop Agent (edge-first)
      Understanding & summariesSelf-hosted LLM + RAGai worker (Node)
      Baseline / anomaly MLscikit-learn, etc.python-worker (scheduled by ai)
      Privacy-sensitiveRules + local CVEdge only (no cloud by default)

      #Edge-first and cloud fallback

      Analysis runs on the employee device when possible. On CPU pressure or timeout, the agent requests cloud fallback via behavior.cloud_infer; ai (Node) or python-worker completes the job without blocking daily work.

      Cloud fallback is paid: available during trial; after trial requires Enterprise. See Trial and paid features.

      #Value loop

      Edge detection → structured events → Server → aggregates / vectors
                              ↓
                    ai (LangChain / LangGraph)
                              ↓
         efficiency reports · process optimization · automation candidates

      Events live in PostgreSQL; embeddings in Qdrant. Keystroke content and raw screen capture are not sent to the LLM by default.
