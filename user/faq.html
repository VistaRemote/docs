      #常见问题（用户）

      #配对与连接

      配对码无效？
      可能已过期（默认约 5 分钟）、输入错误，或已被消费（PAIRING_CONSUMED，不能全班共用一码）；被控端重新生成配对码。

      能看画面但不能操作？
      先确认被控 Agent 已点「允许」，且配对时未勾选「仅观看」。主控端可能未建立控制通道；Win/mac 键鼠注入已实现。刷新会话或联系 IT 检查 Agent 版本。

      一直显示连接中？
      检查网络、防火墙 UDP，或企业是否配置 TURN 服务器。

      VistaRemote 是 MeshCentral 吗？
      不是。VistaRemote 以 WebRTC 远控为主，并具备企业 设备舰队 能力（群控、监控墙、虚拟屏等，见 设备舰队与企业能力）。带外 AMT 等为企业私有化合同能力；注册表、远程打印、登录窗注入等不做。对照表见 竞品对照。

      有没有群控 / 监控墙 / 虚拟屏？
      有，属于 Enterprise 产品能力。购买企业服务后开通；更大监控墙槽位、现场定制可按合同交付。说明见 设备舰队与企业能力。

      #套餐

      试用结束后无法多人观看？
      SFU 需要 Pro/Enterprise，见 套餐与付费。

      企业舰队要单独买吗？
      群控、监控墙、虚拟屏、带外等走 Enterprise（及合同加购）。终端管理可按设备 / 席位计价，详见 套餐与付费 与销售方案。

      开源版可以商用吗？
      个人非商业免费；任何商业使用需购买商业授权，见 开源协议。

      #隐私与 AI

      数据会发到 OpenAI 吗？
      默认私有化部署使用 Ollama + 自建向量库；云推理仅在启用且有权时使用。

      Desktop 上的 AI 做什么？
      本地规则/轻量推理用于行为提示；重任务可走队列到 ai Worker。

      #管理台与远控运维

      如何强制断开远程会话？
      打开 管理控制台 → 会话，对活跃房间执行 强制断开。服务端会先关闭信令 WebSocket，再清空内存房间。被控端也可在桌面置顶连接条断开，见 远程控制。禁用用户不会自动踢掉进行中的会话，仍须在「会话」里断开。

      设备「在线」怎么判定？标签做什么？
      在线 = 该设备最近一次心跳大约在 120 秒内；超时即离线，不表示正在共享画面。可在「设备」编辑 标签 并按标签筛选。吊销设备会让下次心跳失败，与在线判定是两件事。详见 管理控制台。

      管理台怎么回放录制？是 MinIO 播放器吗？
      不是。回放是录制页里的 本机浏览器视频（<video>，支持 seek / 倍速），不是 MinIO 产品播放器。端侧 MediaRecorder 分片上传与 MinIO 可通过 dev 层 recording profile 启用 — 见 Docker 部署。

      ICE 卡住要改 DNS 吗？
      不要先改 DNS。ICE 候选由 Server 下发。管理台 系统 可核对权益标志（FR-WAD-52）。仍失败再查 UDP/防火墙与 TURN，见 远程控制 连接质量。

      权限矩阵可以编辑吗？
      不能。权限页是 只读 对照（平台 RBAC / 组织角色）。角色与权限开通由企业实施 / 平台管理员按组织策略配置。说明见 管理控制台。

      管理台 CSV 怎么导出？
      导出的是当前筛选/已加载的列表（默认客户端导出，除非该页另有说明；审计 CSV 走服务端筛选，含结果）。用户、设备、安全、任务、订单、组织、录制等页在已实现处有 CSV 按钮；组织详情抽屉内 SupportGrant 列表也可 导出授权 CSV（1.33.0）。这不是全库/数仓导出，也不是账单/支付导出。说明见 管理控制台。

      概览卡片和列表筛选能用 URL 打开吗？
      可以。概览指标卡片和多数列表筛选支持 URL 查询种子（例如 /devices?online=offline、/users?planExpiry=expired、/audit?result=denied、/recordings?status=failed）。权限矩阵上的搜索只是只读筛选，不是可编辑角色。详见 管理控制台。

      安全事件的静音规则怎么用？
      在 管理控制台 → 安全事件 配置静音类型（告警规则 lite）。列表默认应用已保存规则（Switch「应用静音规则」）；关掉或通过 URL ?applyMute=false 可查看全部类型。高危横幅计数仍排除静音类型。

      SupportGrant 在哪管理？撤销会踢会话吗？
      组织详情抽屉内 SupportGrant：为 IT 协助创建 / 列出 / 撤销临时授权，并可 导出授权 CSV（当前筛选/已加载行）。撤销确认框可选「撤销并断开相关会话」（?kickSessions=true，默认关）。权限矩阵仍只读。详见 管理控制台。

      系统页的权益标志是什么？
      管理台 系统 只读展示 entitlementMode、entitlementBaseUrlConfigured、webhookSecretConfigured（GET /api/v1/admin/system/entitlement，FR-WAD-52），不展示密钥。可复制权益状态 JSON；不是改套餐入口。见 管理控制台。生产 webhook / 模拟支付核对见 生产支付就绪。

      录制回放 URL 过期怎么办？MinIO EntityTooSmall？
      录制页播放器经短时签名 playback-url 拉流（含 expiresAt）；过期可刷新。若 failedReason 含 EntityTooSmall / part size，列表会提示 Agent 应将非末片合并至 ≥5 MiB（桌面端 ≥1.30；memory:// 仍允许小分片）。见 管理控制台。

      监控墙是什么？怎么开通？
      监控墙是 Enterprise 多屏观察能力：缩略图低成本观察多台设备，发现异常后点选进入高质量远控；更大槽位可按企业合同加购。说明见 设备舰队与企业能力 与 管理控制台。

      旁观 / 观察票据返回什么？
      管理台对房间发起观察时，服务端返回观察票据（含信令与 SFU 相关参数），用于墙内或旁观拉流。见 管理控制台。

      监控墙布局会随改槽位自动保存吗？
      不会。URL s0–s3 优先；无种子时从 GET /admin/monitor-wall/layout 恢复；须点 保存布局（PUT，admin.write）才会持久化。见 管理控制台。

      录制摘要任务怎么跳到录制（1.37.0）？
      「任务」里类型 recording.summarize、id 为 summarize-{recordingId} 的行，操作 列点 录制 → /recordings?recordingId=…。任务筛（id、name、state、failedReason）与 URL 同步；概览「失败任务」打开 /jobs?state=failed。

      效率报告怎么打开录制列表（1.37.0）？
      「效率报告」点 打开录制列表 — 把当前 userId / sessionId / deviceId / recordingId 子串筛带到 /recordings（汇总周期不会传递，仅筛选项）。

      审计 layout 行与监控墙（1.37.0 / 1.38.0）？
      审计筛 监控墙 layout（admin.monitor_wall.layout）。1.38.0 起 保存布局 审计 meta 含 roomIds 及首个 roomId。匹配行 关联 列 监控墙 — /monitor-wall，或 /monitor-wall?s0=<roomId>（meta / resource / target 的 roomId / room_id）。仅槽位 0 种子；不是 SFU 多路已交付。见 管理控制台。

      用户抽屉关联深链怎么用（1.38.0）？
      「用户」打开详情抽屉，点 查看会话 / 录制 / 订单 / 设备 / 审计 — 分别打开 /sessions?userId=…、/recordings?userId=…、/orders?userId=…、/devices?ownerId=…、/audit?actorId=…。见 管理控制台。

      设备怎么从活跃会话跳到监控墙（1.38.0）？
      「设备」行若关联活跃会话，操作 列 监控墙 → /monitor-wall?s0=<sessionId>。仅填充槽位 0；不会自动发起 SFU 多路或墙内旁观。见 管理控制台。

      会话怎么按用户 ID 筛选（1.38.0）？
      「会话」可按 用户 ID 筛选，并与 ?userId= URL 同步（用户抽屉「查看会话」会种子此参数）。见 管理控制台。

      管理台哪里看近期配对码（1.39.0）？
      打开 管理控制台 → 运营管理 → 配对（/pairings）。页面请求 GET /api/v1/admin/pairings（须 admin.read），列出 PostgreSQL 近期配对码（默认 100 条；可选 limit 1–500）。可按设备 ID、owner 用户 ID、配对码筛选，并与 ?deviceId=、?userId=、?numericCode= URL 同步。行 设备 / 用户 分别打开 /devices?deviceId=、/users?userId=（设备 owner）。只读 — 改码长/TTL 请到 系统 配对策略；被控端在 Agent 生成配对码。见 管理控制台。

      系统配对策略与配对行怎么跳转（1.40.0）？
      系统 页 配对策略 区 打开配对 → /pairings；配对 列表行 会话 → /sessions?sessionId=…（有 sessionId 时）。

      怎么筛已消费配对码？概览/设备怎么进配对（1.41.0）？
      配对 页 已消费 下拉（已消费 / 未使用 / 全部），与 ?consumed=yes|no 及 GET /api/v1/admin/pairings 同步（yes = 有 consumedAt）。也可从 概览 → 配对 卡片，或 设备 → 操作 → 配对（预填 ?deviceId=）进入。见 管理控制台。

      用户抽屉怎么打开配对？会员页怎么打开订单（1.42.0）？
      「用户」详情抽屉 打开配对列表 → /pairings?userId=…；「会员」标题旁 打开订单列表 → /orders?userId=…（URL ?userId= 或本页 commerce 订单 userId）。见 管理控制台。

      订单怎么打开会员？审计怎么筛配对（1.43.0）？
      「订单」操作 列 会员 → /membership?userId=…（订单有 userId 时；与 1.42.0 会员→订单互为深链）。「审计」动作预设含 pairing.create / pairing.join（服务端自 1.12.0 起写入）。见 管理控制台。

      用户端会员页的账单说明在哪（1.43.0）？
      Web 用户端 /membership 页底有灰色脚注：历史订单由平台管理员在管理后台查看 — 页内无管理台链接。终端用户联系 IT 或销售；运维用管理台 订单 / 会员。见 套餐与付费。

      管理台 403 页能做什么（1.44.0）？
      Forbidden 提供 返回控制台（→ /）；已登录可 使用其他账号登录；未登录可 前往登录。见 管理控制台。

      配对页头审计链接怎么用（1.44.0）？
      配对 页 创建审计 / 加入审计 分别打开 /audit?action=pairing.create、pairing.join。见 管理控制台。

      监控墙提示条写什么？
      说明布局可保存，以及墙内旁观 / 企业多屏观察的使用提示。产品能力与开通见 设备舰队与企业能力。

      已登录还能打开 /login 吗（1.45.0）？
      会 自动跳回控制台（/），并显示「已登录」与回控制台链接。见 管理控制台。

      审计里怎么快速筛配对动作（1.45.0）？
      审计 → 动作筛选下方点 pairing.create / pairing.join 芯片（等同 Pairings 页头审计深链）。见 管理控制台。

      系统页 enforce 为何出现 webhook 告警（1.47.0）？
      entitlementMode=enforce 且 Webhook 密钥未配置 时，入站 POST /api/v1/commerce/webhooks/entitlement 一律 401，直至服务端设非空 ENTITLEMENT_WEBHOOK_SECRET。管理台 系统 可看 webhookSecretConfigured。见 管理控制台；生产清单见 生产支付就绪。

      订单 / 用户列表筛选项会写回 URL 吗（1.47.0）？
      会。订单：id、userId、sku、provider、currency、status；用户：userId、email、status、plan、billingKind、orgId、planExpiry。可书签或分享链接；会员 / 用户抽屉深链仍会种子 ?userId=。见 管理控制台。

      #部署与上线

      生产支付上线前要核对什么？
      按 生产支付就绪 · 核对清单 逐项勾选（mock → sandbox → production）。Entitlement 支付 adapter 已存在；live 商户启用（凭证、notify DNS）为 owner-ops，不在 VistaRemote 仓内。adapter ≠ 生产 PSP 已开通。

      远程控制 15 步验收在哪？
      在已登录被控 Agent + Web 主控上按序走完，见 远程控制 · 人工验收清单。验收前须 退出并重新登录 以刷新运维 JWT；电源 / 锁屏在开发机可先设 dry-run。

      本地 Docker 默认端口？
      core + dev 栈宿主机端口见 Docker 部署（Postgres 5637、Redis 6380、Server 3000；turn / ai / recording / admin 等同页 profile 表）。生产勿将 DB/Redis 映射到宿主机。

      pnpm assert:prod-env 做什么？
      在 deploy/ 目录、启动生产 compose 之前 的只读校验：检查 .env.prod.example 必填键；若已有 compose/.env.prod 则拒绝弱占位；ENTITLEMENT_MODE=enforce 时要求 非空 ENTITLEMENT_WEBHOOK_SECRET。不表示 PSP 已交付。见 Docker 部署 · assert:prod-env 与 生产支付就绪。

      本地录制 MinIO 用哪个端点？
      dev 层 recording profile：compose 内 server → http://minio:9000；宿主机 Desktop Agent → http://127.0.0.1:19000；控制台 19001。生产默认栈 不含 MinIO，须外部 S3。见 Docker 部署 · 录制（MinIO）。
