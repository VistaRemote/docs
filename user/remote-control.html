      #远程控制（用户指南）

      面向 使用 VistaRemote 进行远程协助 的操作人员，非开发人员。

      VistaRemote 把 MeshCentral / MeshAgent 已登录桌面会话里操作员常用的工具收进本产品：看屏、键鼠、剪贴板、文件、终端、聊天、进程、只读服务、电源、主机信息、通知、锁屏、打开网址、截图。画面走 WebRTC，不走 Mesh 的 JPEG 桌面或 server 字节中继。

      本产品 不是 完整 MeshCentral RMM：不做 Intel AMT / IP-KVM、远程打印、注册表、服务启停、WOL 魔术包、UAC/登录窗、文件型剪贴板、USB、音频混音、壁纸切换、远程执行脚本、锁定被控本机键鼠、Agent JS 控制台。

      #AI 协助（默认关闭）

      可选能力，见 AI 协助。没打开时，键鼠、聊天和终端与现在相同。告警不会因此自动远控。对方必须在「允许远程控制」之外再点一次，AI 才会点击和输入。本机 Cursor 或 ChatGPT 也只能经 MCP 操作这场已经允许的会话，不能新开远控。

      #角色

      角色典型场景
      被控端办公室 PC 安装 Desktop Agent，展示配对码
      主控端管理员用手机/浏览器输入配对码，查看并操作远程桌面

      #连接方式（主控端）

      任选一种即可直连同一台被控电脑：

      方式操作
      数字码在被控端查看 6–8 位码，在主控「配对」页输入
      二维码主控扫描被控屏幕上的码（手机/Web）
      链接打开被控提供的 https://…/join/… 或企业下发的短链

      Web 用户端路径：/pairing、/join/{token}。

      Electron Viewer 与浏览器 Web 主控是同一套页面（会话运维侧栏相同）。手机 App 可看屏并操作键鼠，本版本不含文件/终端等运维面板。

      #同时控制多台电脑

      在 我的设备 勾选在线设备，点 控制所选，进入 /control。

      模式谁可用键鼠发到哪里
      焦点（默认）套餐里有远程会话额度的账号只发给当前点选的那一台
      同步Enterprise 群控权益焦点画面上的键鼠发给所有已点「允许」的机器

      剪贴板、文件、终端仍只作用于焦点那一台，不会一起广播。同时打开的高质量画面最多 8 路，并且不超过套餐的并发会话数。回到设备列表再加一台时，已经连上的不会断开。每台被控仍要单独点「允许」。这不是监控墙的缩略图模式。

      #与 Mesh 会话工具的对应

      对照 Mesh 已登录桌面（KVM 会话 / 工具栏 / 同设备上的终端与文件通道）。下列能力已在 VistaRemote 会话内提供（须被控点「允许」，且账号有对应权限）。

      Mesh 侧常见能力VistaRemote 入口
      键鼠 / 滚轮远程画面上直接操作
      仅观看（不控输入）配对页勾选「仅观看」
      文本剪贴板右侧 剪贴板
      文件浏览、上传下载、重命名、复制右侧 文件（用户主目录内）
      终端 / CMD / PowerShell右侧 终端（Windows ConPTY / macOS·Linux PTY）
      会话聊天 / 留言右侧 聊天（被控 Agent 窗口也可回）
      进程列表、结束任务右侧 进程
      服务列表右侧 服务（只读，不能启停）
      重启 / 关机右侧 电源（须确认；数秒后执行）
      主机信息、通知、锁屏、打开 http(s)右侧 主机
      会话截图工具栏 截图（下载到主控本机 PNG）
      同意提示 / 连接条被控点「允许」；桌面置顶连接条可断开
      多显示器工具栏切屏；多窗口最多 2 路
      访客链接配对 链接 / 二维码（一次性、会过期）

      刻意不做成 Mesh 那样的项（不必在会话里找、也不验收）：Ctrl+Alt+Del / 登录窗、锁定被控用户键鼠、壁纸切换、远程 Run 脚本、服务 start/stop、注册表、远程打印、WOL、AMT 硬件 KVM、USB、远程音频、JPEG 画质档、Agent 控制台下发脚本。

      #快速步骤

      #被控端（Desktop）

      1. 安装 VistaRemote Agent（Windows / macOS / Linux）。
      2. 使用企业账号登录（或注册设备）。
      3. 在界面查看 配对码 / 二维码 / 会话链接（Consumer 需手动开始共享；企业 Managed 可能由 IT 预装自动上线，见 Agent 安装）。
      4. 告知主控任选一种方式连接；对方连接后 确认授权 再开始共享屏幕（若策略要求）。

      #主控端（Web 或 Mobile）

      1. 打开企业提供的 VistaRemote 地址（浏览器或 App）。
      2. 在「配对」页输入配对码。
      3. 等待状态变为 已连接 后即可看到远程画面并操作键鼠。

      技术实现细节见 配对与连接（开发者向）。

      #连接质量

      情况建议
      画面卡顿检查双方网络；企业可配置 TURN 中继
      仅局域网可用联系 IT 开放 UDP 或部署 TURN
      多人观看同一会话需 Pro/Enterprise 套餐（SFU）；试用结束后可能受限

      #故障排查：卡住连接与强制断开

      • 一直显示连接中：检查双方网络、防火墙 UDP，以及企业是否配置 TURN。不要先改 DNS。管理台 系统 可核对权益配置标志（FR-WAD-52）；ICE 候选仍由 Server 下发。仍失败再查 UDP/防火墙与 TURN。更多问答见 常见问题。
      • 强制断开：管理员在管理台 会话 对活跃房间执行 强制断开；被控端可用桌面置顶连接条断开。

      #多显示器（主控 Web）

      单屏：默认采集被控主显示器，无选屏步骤。

      被控端有两块及以上屏幕时：

      操作说明
      选屏 / 工具栏切屏连接前或会话中切换当前观看/控制的远程显示器（单路 On-Demand）
      多窗口最多同时显示 2 路画面（同页双格或「弹出窗口」）；每格独立控制，不串屏
      退出多窗口回到单路；仍可用工具栏切屏
      三块及以上屏P2P 只并行 2 路；其余屏通过切屏或后续 SFU 覆盖

      #被控端 Agent

      • 关闭窗口后 Agent 仍在系统托盘运行；可从托盘恢复窗口、断开会话或退出。
      • 托盘可勾选「开机时启动」。
      • Linux：X11 / XWayland 可直接注入；纯 Wayland 需在系统弹出的屏幕共享与远程桌面门户中授权，步骤见 Linux 已登录远控。

      #剪贴板、文件、终端、聊天、进程、服务、电源与主机（Web / Viewer）

      会话已连接且被控授权后，右侧面板可：

      • 双向同步纯文本剪贴板（被控复制后主控会更新）
      • 浏览被控用户主目录、上传/下载、新建文件夹、删除、重命名、复制（jail 内；复制仅普通文件）
      • xterm 终端（Windows ConPTY / POSIX 真 PTY；如 echo / dir / tput cols）
      • 与被控桌面会话聊天
      • 查看进程并结束任务（不能结束系统 pid 或 Agent 自身）
      • 只读查看系统服务列表（不能远程启动或停止服务）
      • 重启 / 关机（须二次确认字面量；数秒后才执行）
      • 查看被控 主机信息（名称 / 系统 / IP）、发送桌面通知、锁屏（须确认）
      • 在被控用系统浏览器打开 http/https 网址（拒绝 file: / javascript:）
      • 工具栏 截图：把当前画面存为 PNG（在主控本机下载，不经过服务器）

      无对应权限的账号看不到终端、服务、电源或主机页。配对勾选「仅观看」时同样没有这些 Tab，也不会建立键鼠通道。

      • 被控在 Agent 窗口允许后才可键鼠/运维；拒绝则仅观看。被控桌面会显示置顶连接条，可一键断开。断开后立即停止注入与运维通道。

      #人工验收清单（一次走完）

      在 已登录 的被控 Agent + Web 主控上按序勾选。验收前请 退出并重新登录（刷新 JWT，使运维权限生效）。电源/锁屏若在开发机上验收，请先设 VISTAREMOTE_POWER_DRY_RUN=1 与 VISTAREMOTE_HOST_DRY_RUN=1，避免真重启/真锁屏。

      #步骤期望
      1被控展示配对码；主控 /pairing 加入画面出现；状态 connected
      2被控未点「允许」键鼠不动；运维无效
      3被控点「允许」键鼠可用；右侧 Tab 出现
      4连接条「断开」立即停止注入
      5剪贴板：主控发送文本 / 被控复制双向纯文本同步
      6文件：列出、上传、下载、新建文件夹、删除、重命名、复制均在用户主目录内；.. 不可逃出
      7终端：打开 xterm，执行 echo；拉大窗口有输出；列数变化（tput cols）
      8聊天互发双方可见；server 审计无正文
      9进程列表；结束一个自己开的测试进程列表刷新；不能结束 Agent
      10服务 Tab只读列表；无启动/停止按钮
      11电源（dry-run 或真机）无确认被拒；确认后提示已安排
      12主机：sysinfo、通知、锁屏（dry-run 或真机）信息可见；被控弹出通知
      13打开 https://example.com；尝试 file://前者在被控浏览器打开；后者报错
      14工具栏「截图」本机下载 PNG
      15配对页勾选「仅观看」再加入无终端/服务/电源/主机 Tab；键鼠不应注入

      本清单之外不做（不必验收）：Intel AMT / IP-KVM、Mesh JPEG KVM、远程打印、注册表、服务启停、WOL、UAC/登录窗/Ctrl+Alt+Del、文件型剪贴板、USB、音频混音、壁纸切换、远程脚本、锁定被控键鼠。

      #安全提示

      • 勿将配对码发给无关人员；配对码会过期，且 一次性消费（PAIRING_CONSUMED），班级不能共用一个码。
      • 结束会话后关闭 Agent 或断开共享。
      • 企业版可启用审计与行为策略（由管理员配置）。
